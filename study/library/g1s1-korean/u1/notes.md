# 현대시 감상: 김소월 「진달래꽃」 — 핵심 정리 (1학년 1학기 국어 샘플)

## 단원 개요
김소월의 「진달래꽃」을 읽고 화자의 상황과 정서, 운율, 구성을 이해하고 감상한다.

## 핵심 개념
### 작품 정보 (출처: 「진달래꽃」)
- 1922년 7월 잡지 《개벽》 25호에 발표, 1925년 시집 《진달래꽃》에 수록
- 갈래: 서정시, 4연 12행
- 이별의 슬픔을 한국 고유의 정서로 드러낸 시

### 내용과 화자 (출처: 작품 본문)
- 상황: 임이 떠나려는 순간('가실 때에는')
- 화자의 말: 1연 '말없이 고이 보내드리오리다' / 2연 '아름따다 가실 길에 뿌리오리다'(진달래꽃) / 3연 '사뿐히 즈려밟고 가시옵소서' / 4연 '죽어도 아니 눈물 흘리오리다'
- 어미 '-오리다'는 정중한 다짐, '-옵소서'는 공손한 청 → 임을 높이는 공손한 어조

### 운율과 구성 (출처: 「진달래꽃」)
- 7·5조의 음수율, 3음보의 전통적인 민요조 율격
- 수미상관: 1연과 4연 첫 두 행이 같은 형태로 반복('나 보기가 역겨워 / 가실 때에는')

### 시인 김소월 (출처: 「김소월」)
- 1902년 평안북도 출생, 1934년 사망, 일제강점기의 시인
- 전통 민요조의 서정시, 향토적 정서
- 1925년 《개벽》에 유일한 시론 〈시혼〉을 발표

## 꼭 외울 것
- 갈래 서정시 / 4연 12행 / 7·5조 3음보 민요조 / 수미상관(1연·4연)
- 정서: 이별의 슬픔 (한국 고유의 정서)
- 시 발표 1922(《개벽》) → 시집 1925

## 헷갈리기 쉬운 것
| 비교 | 뜻 |
|------|----|
| 음수율 | 한 행의 글자 수의 짜임 (7·5조) |
| 음보 | 소리 내어 읽을 때 끊어 읽는 마디 (3음보) |
| 구성(수미상관) | 시 전체의 짜임, 처음과 끝의 반복 |
| 표현법 | 문장 하나의 꾸밈 (대구법, 점층법 …) |

## 자주 하는 오해
- 화자는 임을 원망하며 붙잡는다 → 말없이 보내고 꽃을 뿌리며 눈물을 참겠다고 함
- 시 발표와 시집 발간은 같은 해다 → 1922년 발표, 1925년 시집
- 시혼은 시집 제목이다 → 김소월의 시론(시에 대한 글)

## 시험 포인트
작가·발표 정보, 연·행, 화자의 상황, 정서·태도, 운율(7·5조·3음보), 수미상관, 시구 해석, 김소월 생애, 서술형(조건 낱말 '슬픔', '이별'·'민요조', '1연'·'4연')

## 문항에서 다루지 않은 것
- 반어법·역설: 위키백과 사본에 해당 용어가 없어 정답 근거로 쓰지 않았다(교과서 해설과 다를 수 있음).
- 「서시」: 위키문헌에서 본문을 확인하지 못해 제외했다.

## 개정판에서 추가한 내용 (개정 규칙 적용, 2026-11-15)
- **연별 내용**: 1연 말없이 고이 보냄 / 2연 영변 약산의 진달래꽃을 가실 길에 뿌림 / 3연 놓인 꽃을 사뿐히 즈려밟고 가시라 / 4연 1연 반복, 죽어도 눈물 흘리지 않음 (출처: 작품 본문)
- **청자와 높임 표현**: 말을 듣는 대상은 떠나는 임이고, '-시-', '-오리다', '-옵소서'는 임을 높이는 표현 (출처: 작품 본문, 일반 문법 지식)
- **운율**: 소리의 반복·글자 수의 짜임에서 오는 노래 같은 가락 (일반 지식)
