# 과거 시제와 독해: 한글의 탄생 — 핵심 정리 (1학년 2학기 영어 샘플)

> 이 정리와 지문은 영문 위키백과 「Hangul」(https://en.wikipedia.org/wiki/Hangul, CC BY-SA 4.0)의 사실을 쉬운 영어로 새로 쓰고 요약한 것이며, 같은 조건(CC BY-SA 4.0)으로 공유한다. 실제 교과서·자습서가 아니다.

## 단원 개요
과거에 있었던 일을 나타내는 동사의 과거형, be동사의 과거형(was/were), 일반동사의 과거 부정문·의문문을 익히고, 한글의 탄생을 다룬 짧은 글을 읽는다.

## 핵심 개념
### 동사의 과거형
- 규칙 동사: -ed / -d (use → used, walk → walked, visit → visited)
- 불규칙 동사: go → went, make → made, buy → bought, see → saw, come → came, begin → began, write → wrote, read → read(발음 [red])

### be동사의 과거형
- I / he / she / it / 단수 → was, you / we / they / 복수 → were (예: Hanja was difficult. Many people were not able to read.)

### 일반동사의 과거 부정문·의문문
- 부정문: 주어 + did not(didn't) + 동사원형 (They didn't use Hanja.)
- 의문문: Did + 주어 + 동사원형 ~? (Did King Sejong create Hangul?) / 대답: Yes, he did. / No, he didn't.
- did 뒤에 과거형을 또 쓰면 틀림 (didn't used ✗)

### 지문 요약 (출처: 영문 위키백과 「Hangul」)
- 한글 이전에 한국은 한자(Hanja)를 써 왔다. 한자는 한국어를 표현하기에 잘 맞지 않았고 배우기 어려워 문맹이 많았다.
- 세종대왕(재위 1418~1450)이 이 문제를 풀기 위해 한글을 만들기로 했다.
- 1443년 말~1444년 초에 알려졌고, 1446년 훈민정음(Hunminjeongeum)이라는 책으로 공식 간행되었다. 처음 이름은 훈민정음이다.
- 지배층과 서민 모두 점차 사용했지만 지배층은 오랫동안 한글을 낮춰 보았다. 오늘날 한국어의 주된 문자이다.

## 꼭 외울 것
- 불규칙 동사 과거형(go–went, make–made, buy–bought, begin–began, write–wrote)
- did not / Did 뒤에는 동사원형
- 복수 주어의 과거 be동사는 were

## 헷갈리기 쉬운 것
| 틀린 표현 | 바른 표현 | 이유 |
|-----------|-----------|------|
| She goed | She went | go는 불규칙 |
| He did not went | He did not go | did not 뒤는 원형 |
| They was happy | They were happy | 복수 주어 |
| Did she walked? | Did she walk? | Did 뒤는 원형 |

## 시험 포인트
어휘(difficult, elite, announce), 과거형 판별, was/were, did not·Did 뒤 동사원형, 어법 판단, 대화 완성, 독해(내용 일치·지칭·제목·문장 배열), 서술형(조건 영작, 오류 고쳐 쓰기)

## 문항에서 다루지 않은 것
- 현재완료·과거진행형: 이 단원 범위가 아님
- 한글 자모 수(24자, 51자 등) 같은 세부 수치: 지문에서 다루지 않음

## 개정판에서 추가한 내용 (개정 규칙 적용, 2026-11-15)
- **연결어**: 결과 As a result·so, 원인 because, 대조 However·but, 예시 For example, 추가 In addition (일반 문법 지식)
- **시간 표현과 시제**: 과거(yesterday, last year, ago, in 1446), 미래(tomorrow) (일반 문법 지식)
- **한글의 사용 범위** (출처: 영문 위키백과 「Hangul」): 한국어의 주된 문자(남·북한), 제주어 표기, 인도네시아 찌아찌아어 표기에 제한적으로 사용
- **한글의 자모** (출처: 「Hangul」): 현대 한국어 표기는 기본 글자 24개(자음 14개, 모음 10개)
