## ⚠ 이번 작업 한정 임시 축약 검수 (사용자 지시, 2026-11-15)
사용량 한도 안에서 여러 과목 샘플을 완료하기 위해 **이번 작업에 한해** 검수 단계를 줄였다. `.claude/` 의 문제 출제·검수 규칙 문서는 바꾸지 않았다.
- 하지 않은 것: 4개 검수 에이전트의 별도 호출, 만장일치까지 반복하는 라운드, Opus 내용 검수, slides.html 제작
- 대신 한 것(자체 점검 1회):
  1. `build_library.py --check-unit` — 오류 0, 경고 0 (처음에 Q05 b의 발문이 Q04 a와 같다는 오류 1건 → 수정)
  2. 지문의 사실 10개를 영문 위키백과 「Hangul」 사본과 코드로 대조 — 모두 일치
  3. 문법 정답 점검: did/didn't/Did/could 뒤에 과거형·3인칭형이 오면 오류로 보는 **간단한 규칙 검사기**로 Q04 a, Q05 a·b, Q09 b의 정답이 하나뿐임을 확인. 이 검사기는 내가 정한 정답과 같은 규칙으로 만든 것이라 독립 검증은 아니다.
  4. 독해 보기의 진위를 지문과 대조, 서술형 모범 답안이 조건 낱말(decided·create, was·could not 등)을 지켰는지 확인
  5. 정답 위치 분포(1~5번 3~4개씩), 보기→해설 짝 자동 대응, 채점 기준 합 = 배점
- 알려진 한계: 영어 교사의 독립 검수가 없다. 조건 영작·오류 고쳐 쓰기는 정답이 여러 형태일 수 있어(예: new alphabet / new writing system) 채점 기준에 허용 범위를 일부만 적었다. 지문이 한 편뿐이라 독해 문항이 같은 글에 몰려 있다.
- 상태: 만장일치 검수가 아니므로 **샘플**이다. 정식으로 쓰려면 `/study 1학년 2학기 영어`를 보강 모드로 다시 돌려 4중 검수를 받을 것.
