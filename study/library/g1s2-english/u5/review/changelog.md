# u5 changelog (S1b)

## 기출 원본과 다르게 수정: 밑줄→[ ] (앱 미지원)
앱이 밑줄 서식을 표시하지 못해 발문의 '밑줄 친'을 '[ ]로 표시한'으로 바꾸고 해당 부분에 [ ]를 쳤다. 기출 정답·보기·지문은 그대로다. 별도 안내문(passage)은 두지 않았다.
- u5-Q05-a (2025-2학기-기말-08): '다음 밑줄 친 it' → '다음 [ ]로 표시한 it', 각 보기의 it에 [ ] 표시
- u5-Q06-a (2024-2학기-기말-18): '밑줄 친 부분' → '[ ]로 표시한 부분', to부정사 부분에 [ ] 표시
- u5-Q08-a (2025-2학기-기말-10): '밑줄 친 부분([ ]로 표시)' → '[ ]로 표시한 부분', 문장 범위를 [ ]로 표시
- gate 면제(review/gate-waivers.json)는 쓰지 않는다.
