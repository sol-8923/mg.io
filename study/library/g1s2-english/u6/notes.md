## 핵심 개념

### 1. 의사소통 기능 ① 원하는 것 묻고 말하기 [p102–105, p106 Self Check]
- 묻기: **What would you like to try?** (체험·시도), **What would you like to learn?**, **What would you like to order?**(주문 받는 사람), **What would you like to have?**(먹을 것) [p102·103·105·106]
- 말하기: **I'd like to try a Korean hat.** / **I'd like to learn traditional dances.** / **I'd like to have a hot dog.** / **I'd like to eat some food.** [p102·105·106] 이 단원 쪽의 예문은 모두 `I'd like to + 동사원형` 형태이다(try / learn / have / eat). `I'd`는 `I would`의 축약이다. (`I'd like + 명사`는 이 단원 쪽에 예문이 없다 — 교과서 밖.)
- 발음 팁 [p104 Sound, (교사용·지도서)]: `I'd like`의 I'd는 I would의 줄임말이고 /d/는 거의 발음하지 않는다. 혀를 입천장 앞쪽에 가볍게 대었다가 바로 다음 단어를 발음한다.
- 주문 팁 [p105 Speaking Tip]: 음식을 주문할 때는 **음식 이름과 개수**를 분명히 말한다. 주문 대화 흐름 [p105]: 점원 `Welcome to ABC Food Truck. What would you like to order?` → 손님 `I'd like to have (…).` → 점원 `Okay. Anything else?` → 손님 `I'd like to have (…).` → 점원 `Great. Thank you.`

### 2. 의사소통 기능 ② 권유하기와 권유에 답하기 [p102–103, p106]
- 권유: **How about this gat?** / **How about a sombrero?** / **How about some galbi and kimchi?** / **How about some soup?** `How about + 명사(구)?` [p102·103·106]
- 권유에 답하기: **Okay. It looks great.**, **That sounds good.**, **That sounds fun!**, **Okay. It's beautiful!** [p102·103·106] 앞의 셋은 `감각동사(looks/sounds) + 형용사`이고, `It's beautiful!`은 감각동사가 아니라 **be동사** 문장이다.
- Fun Fun Story <여우와 두루미> [p106, 이미지 확인]: 만화의 빈칸은 2개 — 1컷(두루미) ⓑ `I'd like to eat some food.`, 2컷(여우) ⓐ `How about some soup?`. `That sounds good!`(ⓓ)은 만화에 인쇄된 대사이고, ⓒ `What would you like to have?`는 만화 속에 없는 보기(Self Check 정답 나열용). Self Check 정답(교사용):
  | 기능 | 표현 | 기호 |
  |---|---|---|
  | 원하는 것 묻기 | What would you like to have? | ⓒ |
  | 원하는 것 말하기 | I'd like to eat some food. | ⓑ |
  | 권유하기 | How about some soup? | ⓐ |
  | 권유에 답하기 | That sounds good! | ⓓ |
- 짝 활동 [p103]: 모자(gat / Korean, non la / Vietnamese, beret / French, sombrero / Mexican)와 음식(risotto / Italian, pho / Vietnamese, bibimbap / Korean)을 골라 `What would you like to try? – I'd like to try … – How about …? – That sounds good.`로 권유한다. 예시 대화에서 권유 뒤에 `It's a Mexican hat.`처럼 `It's a + 국적 + 물건`을 덧붙인다.

### 3. 언어 형식 ① 감각동사 + 형용사 [p111, p116 A]
- 정의 [p116 도움 강의 박스(교사용 텍스트·이미지에서 확인, 학생용 포함 여부 미확인)]: 감각동사는 감각을 나타내는 **2형식 동사**. `주어 + 감각동사 + 주격보어(형용사)`.
- 종류와 뜻 [p116 도움 강의 박스(교사용 표시)]: look(~하게 보이다), sound(~하게 들리다), smell(~한 냄새가 나다), feel(~하게 느끼다), taste(~한 맛이 나다)
- 본문·교과서 예문: Tom yum goong **smells good**. [p111·116] / The cat **looks cute**. / The pizza **tastes delicious**. / The wind **feels cold**. / The song **sounds beautiful**. [p116] / Poke **looks colorful**. It **tastes great**. [p108] / It **tastes spicy and sour**. [p111]
- 연습 정답 [p116 Practice A, 그림 확인] (보기 bad / loud / soft / sour): 1 The lemon **tastes sour**. 2 The alarm **sounds loud**. 3 The sweater **feels soft**. 4 The socks **smell bad**. 해설: taste·sound·feel·smell은 감각동사라 뒤에 형용사를 쓴다.
- 조심: 해석이 "~하게"여서 부사를 쓰기 쉽지만 감각동사 뒤에는 **형용사** (예: sounds beautiful, ○ / sounds beautifully, ✕) [지도서 p.135 설명(교사용). 지도서 형성평가(PDF p.139–140)도 이 오류 유형을 다룸]. 명사가 오면 `감각동사 + like + 명사` (예: looks like a lion) [지도서 p.135 More Sentences].
- 감각동사 + 형용사 매칭 [p117 Pair 1, 활동 자료 p.181(PDF 183) 이미지 확인]: 카드 6장의 그림과 제시 형용사 — 꽃 sweet·beautiful / 얼음 cold·hard / 담요 속 고양이 soft·warm / 떡볶이 spicy·delicious / 심벌즈와 개 loud·hard / 초콜릿 sweet·delicious. look·smell·feel·sound·taste 중 하나로 문장을 쓴다(예시 It looks beautiful. [p117]).

### 4. 언어 형식 ② 동명사 [p108·110·111, p116 B, p117]
- 정의 [p116 도움 강의 박스(위와 같은 표시)]: **동사원형 + -ing**, 뜻은 "~하는 것, ~하기". 문장에서 명사 역할(주어·목적어·보어) [지도서 p.136].
- 동명사를 목적어로 쓰는 동사 [p116 도움 강의 박스, 지도서 p.136과 동일]: enjoy(즐기다), finish(끝내다), stop(멈추다), mind(꺼리다), keep(계속 ~하다), consider(고려하다), give up(포기하다)
- 본문·교과서 예문 [p116 B, 본문 p108·110·111]
  | 쓰임 | 예문 | 쪽 |
  |---|---|---|
  | 목적어(enjoy) | People in Hawaii enjoy **eating** fish. / Many Thai people enjoy **eating** spicy food. / Tom enjoys **watching** movies. | p108·111·116 |
  | 목적어(like) | People in Switzerland like **eating** cheese. / I like **playing** baseball. | p110·116 |
  | 목적어(like) | People like **eating** tom yum goong with rice. | p111 |
  | 주어 | **Reading** a book is fun. / **Making** fondue is very easy. / **Making** a movie is not easy. | p116·110 |
- like/love/hate/begin/start/continue는 동명사와 to부정사를 **둘 다** 목적어로 쓴다 [p111(교사용: "to부정사나 동명사를 모두 쓸 수 있음"), 지도서 p.129·136]. 반면 enjoy는 **동명사만** (예: enjoy play → enjoy playing) [p108(교사용), p118 H].
- 연습 정답 [p116 Practice B]: 1 I enjoy **riding** a bike. 2 I like **reading** books. 3 **Playing** badminton is so much fun! (문장 맨 앞 주어 자리라서 대문자 P).
- 활동 [p117 Group 2]: 보드 게임에서 `I like/love/don't like/enjoy + 동사-ing` 문장 만들기(예시: I like / I don't like listening to music). 숨은 동사: take pictures, listen to music, ride a bike, play games, draw pictures, play sports, watch movies, sing, dance. (교과서 밖: -ing 철자 변화 규칙 — e 탈락 등은 이 단원 쪽에 설명이 없다.) 동명사구 주어는 **단수 취급**(Making fondue **is** very easy) [p110(교사용)].

### 5. 본문 Food Around the World [p107–113]
- 읽기 전 [p107 단어 상자 dip·heat·piece·pot·spicy, 이미지 확인]: 그림에서 spicy(매운 음식을 먹는 괴물) / pot(냄비) / dip(찍어 먹는 장면) / heat(냄비 밑 불) / piece(파이 한 조각)에 해당하는 부분 찾기. 음식 사진 연결(훑어 읽기): **1 poke(생선 샐러드 그릇), 2 fondue(냄비), 3 tom yum goong(국물 음식)** (이미지 확인). Reading Tip: 어떤 정보를 찾아야 하는지 먼저 파악하고 정보를 찾아 읽는다.
- 세 음식 비교
  | 구분 | poke 포케 [p108] | fondue 퐁뒤 [p110] | tom yum goong 똠얌꿍 [p111] |
  |---|---|---|---|
  | 나라 | Hawaii, the United States | Switzerland | Thailand |
  | 종류 | famous fish salad | popular cheese dish | popular Thai soup |
  | 이름 뜻·특징 | Poke는 하와이어로 "to cut" | 만들기 매우 쉬움(Making fondue is very easy) | goong은 '새우'(Do You Know?, p111), 새우(shrimp)가 들어 있음 |
  | 맛·모습·냄새 | looks colorful, tastes great | tastes delicious | tastes spicy and sour, smells good, really tasty |
  | 만드는/먹는 법 | 생선을 작은 조각으로 자르고(cut A into B) 그릇에 담고 신선한 채소를 더함(add A to B) | 냄비에 치즈를 데움(heat) → 빵을 작게 자름(cut) → 긴 포크로 빵 조각을 따뜻한 치즈에 살짝 담금(dip) | 사람들은 밥과 함께 먹는 것을 좋아함 |
  | 배경 | 하와이에 섬이 많고 사람들은 생선 먹기를 즐김 | 스위스 사람들은 치즈 먹기를 좋아함 | 태국은 날씨가 매우 덥고 많은 태국 사람들이 매운 음식 먹기를 즐김 |
- 확인 질문(Q1~Q3) [p108·110·111]: Q1 What does poke mean in Hawaiian? → It means "to cut." / Q2 What is fondue? → It's a popular cheese dish in Switzerland. / Q3 How does tom yum goong taste? → It tastes spicy and sour. (교사용 정답). 지도서 More Questions: ➍ How's the weather in Thailand? → It is very hot. ➎ What do Thai people like eating tom yum goong with? → rice(They like eating it with rice.) [p111(교사용)]
- 구문(본문 속, 교사용·지도서 주석 근거)
  - `There are many islands in Hawaii.` — There is/are ~ ("~이 있다"), 뒤 명사의 수에 따라 is/are [p108].
  - `Poke is a famous fish salad from Hawaii.` — from은 출신·기원 [지도서 p.129].
  - `Poke means "to cut"` — "to cut"은 means의 목적어(명사 역할의 to부정사) [p108].
  - `cut A into B`(A를 B로 자르다), `add A to B`(A를 B에 더하다) [p108].
  - `Try it.` / `First, heat…` / `Pick up…` / `Dip…` — 동사원형으로 시작하는 **명령문**, 순서 표현 First, Next, Now, `Let's + 동사원형`(~하자, 제안) [p110].
  - `a piece of bread` — bread는 셀 수 없는 명사라 한 조각은 `a piece of`로 센다 [p110].
  - `Tom yum goong has shrimp in it.` — it = tom yum goong, has는 have의 3인칭 단수 [p111].
  - `It's really tasty.` — tasty(형용사, 맛있는)를 really(부사)가 수식 [지도서 p.130].
  - 비교: **popular(인기 있는)** vs **famous(유명한)** 의미를 구별해 지도 [지도서 p.129].
- 읽은 후 [p112]
  - Read and Complete (세 학생 리뷰, 빈칸 보기 bread / fish / spicy / Thai, p112 이미지 확인): 포케 리뷰 빈칸 **fish**, 퐁뒤 리뷰 빈칸 **bread**, 똠얌꿍 리뷰 빈칸 **Thai**와 **spicy**. (학생 이름과 음식의 짝은 출제 근거로 쓰지 않는다.)
  - Read and Correct (교사용 정답): 1 "to dip" → **to cut**, 2 chicken → **cheese**, 3 cold → **hot**, 4 Switzerland → **Thailand**.
- Meet the World 세계의 디저트 [p113]: 세 학생의 소개를 사진과 연결 — 1 "from Italy, smells like chocolate" → **tiramisu(c)**, 2 "French dessert, hard on the top, Break the top!" → **crème brûlée(b)**, 3 "Korean cookie, tastes sweet" → **약과(a)** (이미지의 연결선 확인). Make Connections: `I like pizza. Pizza is from Italy. It tastes delicious.` 형식으로 좋아하는 다른 나라 음식 소개 → `I like + 음식. + 음식 + is from + 나라. + It tastes + 형용사.`

### 7. 글쓰기·프로젝트 [p114–115]
- My Writing (떡볶이 소개글 모델) [p114]: 제목 `Try Tteokbokki!`, 구성은 ① `I love eating (음식).` ② `It tastes (…) and (…).` ③ `I add (…) to it.` ④ `I love eating it with (…).` ⑤ `Try (음식)! You will love it, too.` 패턴이다. 지도서 평가 언어 형식: ① love eating + 명사 ② taste + 형용사 ③ add + 명사(음식 재료) ④ try + 명사(음식명) [지도서 p.133].
- 점검표 [p114]: 음식의 맛을 묘사했는가 / 음식을 즐기는 자신만의 방법을 포함했는가 / 모든 문장이 오류 없이 정확한가.
- Team Project (레시피 카드) [p115]: Step 1 PLAN(재료 고르기) → Step 2 CREATE(레시피 카드 만들기) → Step 3 SHARE(소개하기). 재료(You Need)와 순서(Steps)로 구성. 예시 Steps는 4단계이며 모두 동사로 시작한다(Fry (…) / Put (…) / Put (…) and mix / Add (…)). 활동 자료 p.180(PDF 181)은 You Need와 Steps 칸이 있는 빈 레시피 카드(이미지 확인). **조리 순서(Steps)는 명령문**으로 쓴다 [p115(교사용·지도서)].

### 8. Check Up 정답·해설 [p118–119, (교사용)]
- A·B 듣기: non la / Korea (위 6번).
- C: 점원이 케이크를 권유 → **How about this (chocolate) cake?** (How about ~?)
- D OX: 1 Poke means "to cut" in Hawaiian. **O** / 2 Poke looks colorful. **O** / 3 Poke is a famous soup from Hawaii. **X**(soup이 아니라 fish salad).
- E 퐁뒤 순서 [p118 Enjoy Fondue]: Step 1 **Heat cheese** in a pot. Step 2 **Cut** bread into small pieces. Step 3 **Dip** a piece of bread into the warm cheese. (보기 cheese / cut / dip)
- F: Thai people enjoy eating **spicy** food. Tom yum goong **tastes** spicy and sour. It has **shrimp** in it.
- G: 1 The shoes smell bad. 2 The dog looks cute. (감각동사 + 형용사, 어순 주어 + 감각동사 + 형용사)
- H: `I enjoy play basketball.` → **playing** (enjoy는 동명사를 목적어로).
- I 글쓰기: kimchijeon 글 완성 [p119, 보기 eat / taste spicy / smell good]: It **smells good**. / Kimchijeon has kimchi in it, so it **tastes spicy**. / I enjoy **eating** it on a rainy day.
- And You?: What would you like to have for dinner? / What's your favorite food? / How does your favorite food taste? (예: I'd like to have bibimbap. / My favorite food is tom yum goong. / It tastes spicy and sour.)

## 자주 하는 오해

- "~하게" 해석 때문에 감각동사 뒤에 부사를 쓴다 → 형용사가 맞다. (지도서가 be동사로 바꿔 보게 안내: The song is beautiful처럼 형용사가 온다.)
- enjoy 뒤에 to부정사나 동사원형을 쓴다 → enjoy playing. (p118 H: I enjoy play basketball → playing)
- 동명사 주어를 복수로 착각해 are를 쓴다 → 동명사(구) 주어는 단수라 `Playing badminton is …`, `Making fondue is …`처럼 단수 is [p116 B3, p110(교사용)].
- Poke의 뜻을 "to dip"으로 오해 → 하와이어 poke는 "to cut". dip은 퐁뒤에서 빵을 담그는 동작 [p108·110·112].
- 포케를 soup으로 오해 → 포케는 fish salad, soup은 tom yum goong [p118 D].
- 퐁뒤 재료를 chicken/bread로 착각 → 퐁뒤는 cheese 요리이고 빵(bread)은 찍어 먹는 재료 [p110·112].
- 똠얌꿍이 스위스 음식이라고 착각 → 태국. 날씨는 cold가 아니라 very hot [p111·112].
- goong을 닭고기로 오해 → goong은 새우, 닭고기를 넣으면 tom yum gai [p111 Do You Know?].
- 권유 대답 `That sounds good.`을 권유 표현으로 착각 → 권유에 **답하는** 표현이다(권유는 How about ~?) [p106 Self Check].
- `It tastes spicy and sour.`의 and는 형용사 두 개를 이은 것이지 문장을 이은 것이 아니다 [p111(교사용)].

## 시험 포인트

(`docs/subjects/영어.md` 0절 기출 유형과 지도서 단원 형성평가(PDF p.139–140)의 문항 유형 기준. 형성평가는 지도서 자체 자료라 구체 문항·보기는 옮기지 않고 유형만 적는다.)

1. **어휘** — 어휘 관계(맛 형용사 sour·spicy·sweet·salty와 다른 성격의 단어), 영어 뜻풀이로 단어 찾기, 빈칸 어휘(culture, dish), 뜻 연결(heat 데우다, dip 살짝 담그다, pot 냄비, piece 조각, mean 의미하다, popular/famous 구별), 두 문장 공통 빈칸(taste·smell·look 같은 감각동사의 여러 쓰임이나 dish·piece).
2. **어법 — 감각동사** — 밑줄 중 어법상 틀린 문장(sounds beautifully / tastes sweetly), 형용사 자리에 알맞지 않은 말(부사) 고르기, 어순 배열(p118 G 유형), 괄호 단어로 영작. '쓰임이 나머지와 다른 것'으로 감각동사 vs be동사 구분도 가능(look at 등은 교과서 밖).
3. **어법 — 동명사** — 동명사가 들어갈 수 있는/없는 문장 고르기(동사에 따라 가능 여부가 다름), enjoy 뒤 동명사 고치기(p118 H 유형), 동명사 주어의 단수 동사, 주어진 단어로 영작, 동명사·to부정사 둘 다 가능한 동사 구분. '쓰임이 나머지와 다른 것'으로 동명사 vs 현재진행형 -ing 구분도 가능하나 현재진행형은 이 단원 쪽에 없다(교과서 밖).
4. **대화** — (A)~(C) 순서 배열(p102 대화 2의 질문 → 희망 → 권유 → 수락 흐름 유형), 빈칸 추론(권유·주문 표현), 어색한 대화 고르기(권유 뒤에 어울리지 않는 응답), 대화 내용 일치/불일치(푸드 트럭, 한국 부스, 모자 사기). 권유→수락/거절 흐름(How about …? → Okay. / That sounds good.), 주문 대화(order → have → Anything else?).
5. **독해** — 세 음식 비교 일치/불일치 (나라, 재료, 맛, 먹는 방법), '답할 수 없는 질문'(본문에 없는 정보: 포케의 가격·재료 종류 등), 문장 순서(퐁뒤 만드는 순서 heat → cut → dip), 빈칸 어휘, 밑줄 대명사 지칭(it = tom yum goong / the fondue), 한국어 선지 일치 문항.
6. **서술형** — 영작(주어진 단어 사용, 어형 변화·단어 추가 개수 지정: 동명사 주어·enjoy+동명사·I'd like to try 문형), 본문에서 단어 찾아 쓰기(cut, cheese, hot, Thailand 같은 Read and Correct 형태), 어법 오류 찾아 고치기(감각동사 뒤 부사 → 형용사, enjoy play → playing), 보기에서 골라 완성(Heat/Cut/Dip, spicy/tastes/shrimp), 글쓰기 완성(It smells good. It tastes spicy. I enjoy eating it.).
7. **쓰기 평가 방향** [지도서 p.133] — 언어 형식 ① love eating + 명사 ② taste + 형용사 ③ add + 음식 재료 ④ try + 음식명이 맞는지, 어휘·철자.
8. **말하기 평가 방향** [지도서 p.124] — 원하는 것을 묻고 말하는 표현을 상황에 맞게 사용, 언어 사용, 유창성, 협업·참여(과정 중심 수행평가).
