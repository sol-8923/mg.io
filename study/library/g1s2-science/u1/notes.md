# 1학년 2학기 과학 · 물질의 상태 변화 핵심 정리 (샘플)
> 샘플 단원 — 실제 교과서 원문 없이 자체 작성한 정리. 출처 표기는 "샘플 자료".

## 핵심 개념
- **입자의 운동**: 확산(입자가 스스로 퍼져 나감), 증발(액체 표면의 입자가 기체로 날아감). 온도가 높을수록 활발.
- **상태 변화**: 융해(고→액), 응고(액→고), 기화(액→기), 액화(기→액), 승화(고↔기).
- **입자 배열**: 고체 규칙적·가까움·진동 / 액체 불규칙·비교적 가까움 / 기체 매우 멂·활발.
- **부피·질량**: 상태가 변해도 입자의 종류·수·크기 불변 → 질량 일정, 배열·거리 변화 → 부피 변화. 대부분 고체가 될 때 부피 감소, 물은 예외(얼면 부피 증가).
- **열에너지**: 흡수 — 융해·기화·승화(고→기) / 방출 — 응고·액화·승화(기→고).
- **가열·냉각 곡선**: 수평 구간 = 상태 변화 중(두 상태 공존, 온도 일정). 녹는점 = 어는점, 물질의 특성이라 양과 무관. 양이 많으면 수평 구간이 길어짐.
- **상태 판단**: 녹는점 < 기준 온도 < 끓는점 → 액체.
