# Ⅴ. 힘의 작용 — 핵심 정리 (u5)

> 근거: 중학교 과학 1(정대홍 외) 교과서 인쇄 쪽 p.151~190 (PDF 쪽 = 인쇄 쪽 + 2). 모든 사실에 출처 쪽수를 적었다. 교과서 용어를 그대로 쓴다.

## 단원 개요
- 1. 여러 가지 힘: 힘의 표현과 평형 → 중력 → 탄성력 → 마찰력 → 부력 (p.154~169)
- 2. 힘과 우리 생활: 알짜힘 → 힘과 운동 → 여러 가지 힘의 이용 (p.174~183)

## 핵심 개념

### 1. 힘의 표현과 평형 (p.154~155)
- 과학에서의 힘 = 물체의 **모양이나 운동 상태를 변화시키는 원인**. 운동 상태는 물체의 **속력과 운동 방향**을 나타낸다. (p.154)
- 힘을 나타낼 때는 **힘의 크기, 방향, 작용점**을 함께 표시한다. 크기가 같고 방향이 같아도 작용점이 다르면 모양이나 운동 상태가 달라질 수 있다. (p.155)
- 화살표로 나타낸다: **화살표의 길이 = 힘의 크기, 화살표의 방향 = 힘의 방향, 화살표의 시작점 = 힘의 작용점**. 힘의 크기 단위는 주로 **N(뉴턴)**. (p.155)
- **힘의 평형**: 한 물체에 **같은 크기의 두 힘이 같은 직선상에서 서로 반대 방향**으로 작용하는 경우. 줄다리기에서 줄이 어느 쪽으로도 움직이지 않는 것이 예. (p.155)

### 2. 중력 (p.156~158)
- 중력 = 지구가 물체를 끌어당기는 힘. 방향은 **지구 중심 방향**. (p.157)
- **무게** = 물체에 작용하는 중력의 크기, 단위는 힘의 단위와 같은 N. (p.157)
- 천체마다 중력의 크기가 달라 무게도 다르다. **달에서의 중력은 지구의 약 1/6**, 달에서 잰 무게도 지구의 약 1/6. (p.158)
- **질량** = 장소가 달라져도 변하지 않는 물체의 고유한 양, 단위 kg·g. (p.158)
- 지구에서 질량 1 kg인 물체의 무게는 약 9.8 N. 무게는 질량에 비례한다. 300 g 사과: 지구 2.94 N, 달 0.49 N. (p.158)

### 3. 탄성력 (p.160~163)
- **탄성** = 변형된 물체가 원래 모양으로 되돌아가려는 성질, **탄성력** = 되돌아가려는 힘. 방향은 변형된 물체가 **원래 모양으로 되돌아가려는 방향**. (p.161)
- 탄성력의 크기는 물체의 **변형 정도(늘어난 길이)에 비례**한다. 용수철이 2 cm 늘어날 때 1 N이면 4 cm, 6 cm에서 2 N, 3 N. (p.161, 163)
- 탄성력을 이용해 힘의 크기를 재는 장치: 용수철저울, 체중계 등. (p.163)

### 4. 마찰력 (p.164~165)
- **마찰력** = 두 물체의 접촉면 사이에서 물체의 **운동을 방해하는 힘**. 운동하는 물체에서는 **운동 방향과 반대**로 작용. (p.165)
- 크기: 물체의 **무게가 무거울수록** 커지고, **접촉면이 거칠수록** 커진다. (p.165)
- 작은 힘으로 당겨 움직이지 않는 것은 접촉면 사이에 마찰력이 작용하기 때문. 5 N으로 밀어도 정지해 있으면 마찰력도 5 N(힘의 평형). (p.165, 187 문제)

### 5. 부력 (p.166~169)
- **부력** = 액체나 기체 속의 물체가 받는, **중력과 반대 방향(위쪽)**으로 밀어 올리는 힘. 배가 뜨는 것은 물이 작용하는 부력, 헬륨 풍선이 올라가는 것은 공기가 작용하는 부력 때문. (p.167)
- 측정: 부력의 크기 = **물에 잠기기 전 힘 센서 값 − 잠겼을 때 값**. 물체가 **잠긴 부분의 부피가 클수록** 부력이 커진다. (p.168~169)
- 물 위에 떠서 정지한 배는 **중력과 부력이 힘의 평형**(크기 같음). 화물을 가득 실은 배는 중력이 더 커서 물에 더 잠기고 더 큰 부력을 받는다. (p.169)

### 6. 알짜힘 (p.174~175)
- **알짜힘** = 한 물체에 여러 힘이 동시에 작용할 때 모든 힘을 합한 힘. 나란한 두 힘: 방향 같으면 **합**(방향도 같음), 반대이면 **차**(큰 힘의 방향), 크기 같고 반대이면 **0**. (p.174)
- 알짜힘이 0이면 힘의 평형 상태 → 속력·운동 방향 변화 없음. 정지한 물체는 계속 정지, 운동하는 물체는 **일정한 방향·속력**으로 운동(예: 무빙워크). (p.175)

### 7. 힘과 운동 (p.176~179)
- 알짜힘이 0이 아니면 운동 상태(속력 또는 운동 방향)가 변한다. (p.177)
- 운동 방향과 알짜힘의 방향이 **같으면 속력 증가, 반대이면 속력 감소, 항상 수직(일정 크기)이면 운동 방향만 변함, 비스듬하면 속력·방향 모두 변함**. (p.177)
- 분류(p.179): 속력만 변함 = 낙하 놀이 기구 / 운동 방향만 변함 = 대관람차(일정한 속력의 원운동) / 속력·방향 모두 변함 = 그네 / 알짜힘 0 = 정지(책상 위 책), 무빙워크.

### 8. 여러 가지 힘의 이용 (p.180~183)
- 책상 위 시계: 중력과 떠받치는 힘이 평형. 물에 뜬 튜브: 부력과 중력 평형. 문 고정 장치: 문이 닫히려는 힘과 마찰력 평형. (p.180)
- 장난감 잠수함: 풍선에 공기를 넣으면 집기병 속 물이 빠져나가 부력 > 무게가 되어 뜬다(가라앉아 있을 때는 부력 < 무게). (p.181)
- 아기 양말 바닥의 고무 = 마찰력(미끄럼 방지), 수중 카메라를 부피 큰 가벼운 물체로 감쌈 = 부력, 키보드 용수철 = 탄성력, 자전거 안장 용수철(충격 흡수)=탄성력, 윤활유로 마찰력 줄임, 병따개 고무 = 마찰력. (p.182~183)

## 꼭 외울 것
- 힘 = 모양·운동 상태(속력, 운동 방향) 변화의 원인. 3요소: 크기·방향·작용점. 단위 N.
- 평형 = 같은 크기, 반대 방향, 같은 직선. 알짜힘 = 힘의 합(같은 방향 합, 반대 차). 알짜힘 0 → 운동 상태 불변.
- 중력(방향: 지구 중심), 무게(N, 장소에 따라 변함) vs 질량(kg, 불변). 달 중력 = 지구의 1/6. 1 kg = 9.8 N.
- 탄성력: 되돌아가려는 방향, 변형 길이에 비례. 마찰력: 운동 반대, 무게·거칠기 클수록 큼. 부력: 위쪽, 잠긴 부피 클수록 큼.

## 헷갈리기 쉬운 것
| 구분 | 무게 | 질량 |
|---|---|---|
| 뜻 | 중력의 크기 | 물체의 고유한 양 |
| 단위 | N | kg, g |
| 장소 | 달에서 지구의 약 1/6 | 변하지 않음 |

| 알짜힘과 운동 방향 | 운동 상태 변화 |
|---|---|
| 같은 방향 | 속력 증가 |
| 반대 방향 | 속력 감소 |
| 항상 수직 | 운동 방향만 변함 |
| 비스듬함 | 속력·운동 방향 모두 변함 |
| 0 | 변화 없음(정지 또는 일정한 속력·방향) |

## 자주 하는 오해
- "힘이 났다(기운)"는 과학에서의 힘이 아니다. 과학에서의 힘은 모양·운동 상태를 바꾸는 원인이다.
- 달에 가면 질량이 줄어든다(X): 무게만 약 1/6, 질량은 그대로.
- 정지해 있으면 힘이 작용하지 않는다(X): 힘이 평형이어서 알짜힘이 0일 뿐이다.
- 마찰력은 항상 운동 방향과 같다(X): 반대 방향.
- 부력은 물속에서만 작용한다(X): 기체 속(헬륨 풍선)에서도 작용.
- 탄성력은 늘어난 길이에 반비례한다(X): 비례.
- 물체의 속도가 일정하면 힘이 작용한다(X): 알짜힘 0이다.

## 시험 포인트
- 합답: 힘의 3요소·평형 조건, 무게/질량 비교(표), 탄성력 그래프, 마찰력 실험 비교, 부력 측정값 해석, 알짜힘 계산, 운동 방향과 알짜힘 관계.
- 계산: 용수철 늘어난 길이·탄성력 비례, 달에서의 무게(1/6), 부력 = 공기 중 값 − 물속 값, 알짜힘(합·차). **단위 포함**.
- 서술: '중력·부력·잠긴 부피'(배가 뜨는 까닭), '알짜힘·마찰력'(굴러가던 공이 멈춤), 힘의 이용 장치의 까닭.
