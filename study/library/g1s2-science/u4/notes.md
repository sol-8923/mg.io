# Ⅳ. 물질의 상태 변화 — 핵심 정리 (중학교 과학 1, 인쇄 쪽수 기준)

> 근거: 학생용 교과서 p.113~150(PDF 쪽 = 인쇄 쪽 + 2). 교과서 용어를 그대로 쓴다. 이 교과서는 '녹는점·끓는점·융해열·기화열' 대신 **녹는 온도·끓는 온도·어는 온도, 열에너지 흡수·방출**이라고 쓴다. (기출 원문에는 옛 용어가 남아 있다 — 문항에서 다루지 않은 용어는 맨 아래에 적음)

## 단원 개요
- Ⅳ-1 물질의 세 가지 상태: 확산과 증발(p.116~119), 물질의 세 가지 상태(p.120~122)
- Ⅳ-2 상태 변화와 열에너지: 여러 가지 물질의 상태 변화(p.128~133), 열에너지를 흡수하는 상태 변화(p.134~137), 열에너지를 방출하는 상태 변화(p.138~141), 상태 변화할 때 출입하는 열에너지의 이용(p.142~143)

## 핵심 개념
### 1. 확산과 증발 (p.118~119)
- **확산**: 물질을 이루는 입자가 스스로 운동하여 주변으로 퍼져 나가는 현상. 예) 차가 우러나는 것, 파스 냄새, 식초가 냉면 전체에 퍼지는 것, 물에 떨어뜨린 색소가 퍼짐. 액체뿐 아니라 기체에서도 일어난다. (p.118~119)
- **증발**: 액체를 이루는 입자가 스스로 운동하여 액체 표면에서 떨어져 나와 기체로 변하는 현상. 예) 어항 속 물이 줄어듦, 젖은 빨래가 마름, 손 소독제 흔적이 사라짐(질량 감소). (p.118~119)
- 확산과 증발은 물질을 이루는 **입자가 스스로 끊임없이 운동**하기 때문에 나타난다. 향수 냄새가 퍼지는 것은 향수 입자가 증발하고 공기 중으로 확산하기 때문이다. (p.119)
- 증발은 기화에, 응결은 액화에 해당한다. (p.129 말풍선)

### 2. 물질의 세 가지 상태 (p.120~122)
| 구분 | 고체 | 액체 | 기체 |
|---|---|---|---|
| 모양 | 일정(용기와 무관) | 용기에 따라 변함, 흐르는 성질 | 용기에 따라 변함, 흐르는 성질 |
| 부피 | 일정, 힘을 가해도 거의 변하지 않음 | 일정, 힘을 가해도 거의 변하지 않음 | 용기·외부의 힘에 따라 쉽게 변함 |
| 입자 사이 거리 | 매우 가깝다 | 고체보다 조금 멀지만 비교적 가깝다 | 매우 멀다(공간이 많다) |
| 입자 배열 | 규칙적 | 고체보다 불규칙 | 매우 불규칙 |
| 입자 운동 | 제자리에서 진동할 뿐 자유롭게 움직일 수 없다 | 고체보다 자유롭게 움직인다 | 매우 활발, 공간을 가득 채운다 |
- 특징이 서로 다른 까닭: 입자 사이의 거리, 배열 상태, 움직임 정도가 다르기 때문. (p.122)
- 기체의 부피가 쉽게 변하는 것은 입자 사이의 거리가 매우 멀기 때문(p.124 개념 정리).

### 3. 여러 가지 물질의 상태 변화 (p.129~133)
- **상태 변화**: 물질의 온도가 높아지거나 낮아지면서 상태가 변하는 것. 종류: **융해**(고체→액체), **응고**(액체→고체), **기화**(액체→기체), **액화**(기체→액체), **승화**(고체↔기체, 액체를 거치지 않음). (p.129)
- 예) 융해: 버터가 녹는다 / 응고: 촛농이 굳는다 / 기화: 젖은 빨래가 마른다 / 액화: 차가운 컵 표면에 물방울 / 승화: 응달의 눈사람이 녹은 흔적 없이 작아짐(고체→기체), 겨울철 나뭇잎에 서리(기체→고체).
- 상태가 변해도 입자의 **종류와 개수**는 변하지 않으므로 **질량·물질의 성질은 변하지 않는다.** 입자 사이의 거리와 배열이 달라져 **부피**가 변한다. (p.130~133)
- 융해, 기화, 고체→기체 승화: 입자가 불규칙하게 배열되고 입자 사이 거리가 멀어져 **부피가 커진다**. 응고, 액화, 기체→고체 승화: 입자가 규칙적으로 배열되고 거리가 가까워져 **부피가 작아진다**. (p.133)
- 물은 얼 때 입자가 육각형으로 배열되어 입자 사이 공간이 커지므로 응고할 때 부피가 커진다(일반 물질과 다름). (p.133)

### 4. 열에너지를 흡수하는 상태 변화 (p.134~137)
- **열에너지**: 온도가 다른 두 물체 사이에서 이동하는 에너지로, 물질의 온도나 상태를 변화시킨다. (p.136)
- 흡수: **융해, 기화, 고체→기체 승화.** 열에너지를 흡수해 입자 운동이 활발해지고 입자가 불규칙하게 배열된다. 흡수한 열에너지는 온도 변화가 아니라 상태 변화에 쓰여 **상태 변화 중에는 온도가 일정**(녹는 온도·끓는 온도). (p.136)
- 주위의 열에너지를 흡수하므로 **주위의 온도가 낮아진다.** 예) 물놀이 후 물 밖으로 나오면 시원함(몸에 묻은 물이 기화). (p.137)
- 가열 곡선(p.136 그림 9): 고체 → (융해, 녹는 온도에서 일정, 고체+액체) → 액체 → (기화, 끓는 온도에서 일정, 액체+기체) → 기체.

### 5. 열에너지를 방출하는 상태 변화 (p.138~141)
- 방출: **응고, 액화, 기체→고체 승화.** 입자 운동이 둔해지고 입자가 규칙적으로 배열된다. 냉각해도 상태 변화 중에는 온도가 일정(어는 온도). (p.140)
- 주위로 열에너지를 방출하므로 **주위의 온도가 높아진다.** 예) 액체 파라핀이 응고하며 열 방출(온열 찜질), 사과꽃에 물을 뿌려 냉해 방지, 이글루 벽에 물을 뿌림. (p.138, 141)
- 냉각 곡선(p.140 그림 11): 기체 → (액화, 일정) → 액체 → (응고, 어는 온도에서 일정, 액체+고체) → 고체.

### 6. 열에너지 출입의 이용 (p.142~143)
- 항아리 냉장고: 모래의 물이 기화하며 열에너지 흡수. 냉장고: 증발기에서 냉매가 기화하며 열 흡수(안이 시원), 응축기에서 냉매가 액화하며 열 방출(뒤쪽이 뜨거움). 에어컨·냉장고의 냉매는 기화와 액화를 반복하며 열에너지를 출입시키는 물질. (p.142)
- 증산 작용, 인공 안개: 기화하며 열 흡수로 주변 온도 낮춤. 우주복 안감: 융해(흡수)·응고(방출)로 체온 유지. 드라이아이스: 승화하며 열 흡수로 아이스크림케이크가 잘 안 녹음. (p.143)
- 아이스팩·냉찜질 팩: 고체→액체로 변하며 열에너지를 흡수하는 원리(p.137, 144 퀴즈).

## 꼭 외울 것
- 확산(입자가 퍼짐) vs 증발(액체 표면 입자가 기체로).
- 상태 변화 5종과 방향, 승화는 양방향(액체를 거치지 않는다).
- 질량·입자의 종류·개수·물질의 성질 불변 / 부피·입자 배열·입자 사이 거리 변함.
- 흡수: 융해·기화·(고→기)승화 → 주위 온도 낮아짐 / 방출: 응고·액화·(기→고)승화 → 주위 온도 높아짐.
- 상태 변화 중 온도 일정(가해 준·방출하는 열에너지가 상태 변화에 쓰임).

## 헷갈리기 쉬운 것
| 헷갈림 | 바로잡기 |
|---|---|
| 서리·성에는 액체를 거친다 | 기체가 액체를 거치지 않고 바로 고체가 되는 **승화**(p.129) |
| 눈사람이 작아지는 것도 융해 | 녹은 흔적이 없으면 고체→기체 **승화** |
| 상태가 변하면 질량도 변한다 | 입자 종류·개수가 같아 **질량 불변**, 부피만 변함 |
| 물질이 얼면 항상 부피가 줄어든다 | 물은 응고할 때 **부피가 커진다**(p.133) |
| 가열하는 동안 온도는 계속 오른다 | 상태 변화 중에는 **일정**(p.136) |
| 증발과 확산은 같은 말 | 증발=액체→기체, 확산=입자가 퍼져 나감. 향수는 증발하고 확산한다 |

## 자주 하는 오해
- "고체 입자는 움직이지 않는다" → 제자리에서 진동한다(p.122).
- "기체는 입자가 없는 곳이 많아 입자가 가벼워 부피가 변한다" → 입자 사이 거리가 매우 멀어서 힘을 가하면 부피가 쉽게 변한다.
- "얼음 조각상 옆이 시원한 것은 얼음이 차가운 기운을 내보내서" → 얼음이 융해하며 주위에서 열에너지를 흡수하기 때문(p.145 궁금증 해결).

## 시험 포인트
- 입자 모형 그림(가~다, 가~바)에서 상태·상태 변화 이름·열 출입·부피 변화 판단(합답).
- 가열·냉각 곡선의 구간별 상태, 온도 일정 구간, 열에너지 흡수·방출.
- 현상 분류(성에·서리·이슬·김·물방울·빨래·고드름·드라이아이스·나프탈렌 등).
- 서술: 확산·증발, 기체 부피가 쉽게 변하는 까닭(입자 사이 거리), 냉각 후 표면이 움푹 들어가는 까닭, 열에너지 흡수·방출로 주위 온도 설명, 에어컨 증발기·응축기.

## 문항에서 다루지 않은 것 (교과서에 없거나 용어가 다름)
- 녹는점·끓는점·융해열·기화열·응고열·액화열·승화열 용어, 상태 변화 때 출입하는 열에너지의 크기 비교, 입자 사이의 인력, 증발에 영향을 주는 요인(표면적·바람·습도), 확산이 잘 일어나는 조건(질량 등), 끓음과 증발의 차이. 기출 원문 중 이런 내용에 의존하는 문항은 편입에서 제외했다.
- 교과서가 '녹는 온도·끓는 온도'라고 쓰는 곳에 기출 원문은 '녹는점·끓는점'을 쓴다(표 해석 문항 1개에서 원문 용어를 그대로 둠).
