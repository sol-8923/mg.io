Ⅳ-1 · 확산과 증발

확산과 증발 p.118~119

확산

물질을 이루는 입자가 스스로 운동하여 주변으로 퍼져 나가는 현상. 액체뿐 아니라 기체에서도 일어난다.

  • 차가 우러나는 것
  • 파스 냄새가 퍼짐
  • 식초가 냉면 전체에 퍼짐
  • 물에 떨어뜨린 색소가 퍼짐

증발

액체를 이루는 입자가 스스로 운동하여 액체 표면에서 떨어져 나와 기체로 변하는 현상.

  • 어항 속 물이 줄어듦
  • 젖은 빨래가 마름
  • 손 소독제 흔적이 사라짐 (질량 감소)

공통 원인

물질을 이루는 입자가 스스로 끊임없이 운동하기 때문이다.

향수 냄새가 퍼지는 까닭

향수 입자가 증발하고 공기 중으로 확산하기 때문이다. 증발은 기화, 응결은 액화에 해당 (p.129)

Ⅳ-1 · 물질의 세 가지 상태

고체·액체·기체의 특징 p.120~122

구분고체액체기체
모양일정 (용기와 무관)용기에 따라 변함, 흐르는 성질용기에 따라 변함, 흐르는 성질
부피일정, 힘을 가해도 거의 변하지 않음일정, 힘을 가해도 거의 변하지 않음용기·외부의 힘에 따라 쉽게 변함
입자 사이 거리매우 가깝다고체보다 조금 멀지만 비교적 가깝다매우 멀다 (공간이 많다)
입자 배열규칙적고체보다 불규칙매우 불규칙
입자 운동제자리에서 진동할 뿐 자유롭게 움직일 수 없다고체보다 자유롭게 움직인다매우 활발, 공간을 가득 채운다
왜 다를까 입자 사이의 거리·배열 상태·움직임 정도가 다르기 때문이다. 기체의 부피가 쉽게 변하는 것은 입자 사이의 거리가 매우 멀기 때문이다. (p.122, 124)

Ⅳ-2 · 여러 가지 물질의 상태 변화

상태 변화 5가지 p.129

상태 변화 : 물질의 온도가 높아지거나 낮아지면서 상태가 변하는 것.

예시

  • 융해 (고체→액체) 버터가 녹는다
  • 응고 (액체→고체) 촛농이 굳는다
  • 기화 (액체→기체) 젖은 빨래가 마른다
  • 액화 (기체→액체) 차가운 컵 표면에 물방울
  • 승화 (고체↔기체, 액체를 거치지 않음) 응달의 눈사람이 녹은 흔적 없이 작아짐 (고체→기체), 겨울철 나뭇잎에 서리 (기체→고체)
6
Ⅳ-2 · 상태 변화와 입자

변하는 것, 변하지 않는 것 p.130~133

변하지 않는 것

입자의 종류와 개수가 그대로이므로 질량과 물질의 성질은 변하지 않는다.

변하는 것

입자 사이의 거리와 배열이 달라져 부피가 변한다.

상태 변화입자 배열·거리부피
융해, 기화, 고체→기체 승화불규칙, 거리가 멀어짐커진다
응고, 액화, 기체→고체 승화규칙적, 거리가 가까워짐작아진다

예외 : 물

물은 얼 때 입자가 육각형으로 배열되어 입자 사이 공간이 커지므로, 응고할 때 부피가 커진다. (일반 물질과 다름, p.133)

Ⅳ-2 · 열에너지의 출입

흡수하는 변화 vs 방출하는 변화 p.136~141

열에너지 : 온도가 다른 두 물체 사이에서 이동하는 에너지로, 물질의 온도나 상태를 변화시킨다. (p.136)

열에너지 흡수

  • 융해, 기화, 고체→기체 승화
  • 입자 운동이 활발해지고 불규칙하게 배열
  • 주위에서 흡수 → 주위의 온도가 낮아짐
  • 예) 물놀이 후 물 밖으로 나오면 시원함 (몸의 물이 기화)
  • 예) 아이스팩·냉찜질 팩 (고체→액체)

열에너지 방출

  • 응고, 액화, 기체→고체 승화
  • 입자 운동이 둔해지고 규칙적으로 배열
  • 주위로 방출 → 주위의 온도가 높아짐
  • 예) 액체 파라핀이 응고하며 열 방출 (온열 찜질)
  • 예) 사과꽃·이글루 벽에 물을 뿌림
궁금증 얼음 조각상 옆이 시원한 것은 차가운 기운을 내보내서가 아니라, 얼음이 융해하며 주위에서 열에너지를 흡수하기 때문이다. (p.145)
8
Ⅳ-2 · 가열 곡선과 냉각 곡선

상태 변화 중에는 온도가 일정 p.136, 140

가열 (p.136)

고체 → 융해(녹는 온도, 고체+액체) → 액체 → 기화(끓는 온도, 액체+기체) → 기체

냉각 (p.140)

기체 → 액화(일정) → 액체 → 응고(어는 온도, 액체+고체) → 고체

상태 변화 중 온도가 일정한 까닭 : 흡수·방출하는 열에너지가 온도 변화가 아니라 상태 변화에 쓰이기 때문이다.

Ⅳ-2 · 열에너지 출입의 이용

생활 속 열에너지 출입 p.142~143

사례원리
항아리 냉장고모래의 물이 기화하며 열에너지 흡수
냉장고·에어컨증발기에서 냉매가 기화하며 열 흡수(안이 시원), 응축기에서 냉매가 액화하며 열 방출(뒤쪽이 뜨거움). 냉매는 기화와 액화를 반복하며 열에너지를 출입시키는 물질.
증산 작용, 인공 안개기화하며 열 흡수 → 주변 온도를 낮춤
우주복 안감융해(흡수)·응고(방출)로 체온 유지
드라이아이스승화하며 열 흡수 → 아이스크림케이크가 잘 안 녹음

꼭 외울 것

핵심 암기 5가지

  • 확산(입자가 퍼져 나감) vs 증발(액체 표면 입자가 기체로).
  • 상태 변화 5종 : 융해(고→액), 응고(액→고), 기화(액→기), 액화(기→액), 승화(고↔기, 액체를 거치지 않음).
  • 불변 : 질량·입자의 종류·개수·물질의 성질 / 변화 : 부피·입자 배열·입자 사이 거리.
  • 흡수 : 융해·기화·(고→기)승화 → 주위 온도 낮아짐.
    방출 : 응고·액화·(기→고)승화 → 주위 온도 높아짐.
  • 상태 변화 중 온도 일정 (열에너지가 상태 변화에 쓰임).

헷갈리기 쉬운 것

바로잡기와 자주 하는 오해

헷갈림바로잡기
서리·성에는 액체를 거친다기체→고체 승화 (p.129)
눈사람이 작아지면 융해녹은 흔적이 없으면 고체→기체 승화
상태가 변하면 질량도 변한다입자 종류·개수 같아 질량 불변, 부피만 변함
얼면 항상 부피가 줄어든다물은 응고할 때 부피가 커진다
가열 중 온도는 계속 오른다상태 변화 중에는 일정
증발과 확산은 같은 말증발=액체→기체, 확산=퍼져 나감

이렇게 오해하지 말자

  • "고체 입자는 움직이지 않는다" (X) → 제자리에서 진동.
  • "기체는 입자가 가벼워 부피가 변한다" (X) → 입자 사이 거리가 매우 멀어 힘을 가하면 부피가 쉽게 변한다.
  • "얼음 조각상이 차가운 기운을 내보낸다" (X) → 융해하며 열에너지 흡수.
