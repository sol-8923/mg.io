# 사회 ① Ⅴ. 아메리카 — 핵심 정리 (교과서 p.92~105)

> 출처 표기 `[pN]`은 교과서 인쇄 쪽. 교과서 문장을 옮기지 않고 요점만 정리한다. 지도·그림 속 글자는 추출이 깨져 있어(p.90~91, p.94 기후 분포도, p.97 민족·인종 분포도, p.102 실리콘 밸리 분포도) 그 쪽의 위치·수치는 근거로 쓰지 않고, 본문 문장과 교사용 교과서·지도서의 같은 내용으로 확인했다.

## 1. 아메리카의 국가 및 주요 도시와 자연환경 (p.92~95)

### 지역 구분과 국가 [p93]
- 지리적 구분: **파나마 지협**을 경계로 북아메리카와 남아메리카. (지협 = 두 육지를 잇는 좁고 잘록한 땅)
- 문화적 구분: **리오그란데강**을 기준으로 앵글로아메리카와 라틴 아메리카.
- 북아메리카: 미국, 캐나다, 멕시코, 카리브해 연안 국가들 / 남아메리카: 브라질, 아르헨티나, 콜롬비아, 페루 등.

### 주요 도시 [p93]
| 도시(국가) | 특색 |
|---|---|
| 토론토(캐나다) | 정치·경제·문화의 중심지. 인구의 50% 이상이 이민자, 200여 민족이 130여 개 언어·사투리 사용 |
| 몬트리올(캐나다) | 프랑스 문화가 발달, 다양한 국제 행사 |
| 뉴욕(미국) | 정치·경제·금융 중심, 월가를 중심으로 세계 경제의 중심 역할, 국제 연합(UN) 본부 |
| 로스앤젤레스(미국) | 다양한 문화 산업(대중문화·영화) 발달 [p93, p96] |
| 시카고(미국) | 과거 공업 발달로 발전 |
| 휴스턴(미국) | 석유 산업과 항공·우주 산업의 발달로 성장 |
| 멕시코시티(멕시코) | 멕시코의 수도, 해발 약 2,200m, 과거 아스테카 문명의 중심지 |
| 쿠스코(페루) | 잉카 문명의 유산을 간직한 도시 |
| 상파울루(브라질) | 남아메리카에서 인구가 가장 많은 도시, 남아메리카 금융의 중심지 |
| 쿠리치바(브라질), 아바나(쿠바) | 생태 도시로 주목 |

### 지형 [p94]
- 대륙 **서쪽**: 높고 험준한 산지 / **동쪽**: 오랜 기간 침식을 받은 낮은 산지나 고원 / **가운데**: 평지·분지.
- 북아메리카: 서쪽 로키산맥(남북), 동쪽 애팔래치아산맥, 가운데 대평원, 미국 중부를 남북으로 흐르는 미시시피강.
- 남아메리카: 서쪽 안데스산맥(남북), 동쪽 브라질고원, 가운데 아마존강이 흐르는 아마존 분지.
- 자연환경 그림지도 활동 [p95]: 로키산맥(서부 산맥·화산 지형·빙하 지형), 그랜드 캐니언(강의 침식으로 생긴 협곡·세계 자연 유산), 아마존 열대림 지대(세계 최대 열대림·지구의 허파), 우유니 사막(소금 사막·고산 지대·세계적인 리튬 매장지).

### 기후 [p94]
- 북아메리카 북부: 주로 냉대·한대 / 미국 남동부: 온대 / 대륙 내부·서부: 건조 / 멕시코 남부·카리브해: 열대.
- 남아메리카: 적도 중심 열대, 남부 일부 온대. 적도 주변 안데스 산지는 **고산 기후**(키토, 보고타 등 고산 도시 발달).
- 사진 설명 [p94]: 그린란드의 고상 가옥은 여름에 얼었던 땅이 녹아 건물이 무너질 수 있어 기둥을 깊이 박아 띄워 짓는다(한대 기후). 보고타는 고산 지역이라 덥고 습한 지역보다 쾌적.

## 2. 다양한 민족과 인종으로 구성된 아메리카 (p.96~99)

### 인구 특징 [p97]
- **앵글로아메리카**: 유럽인 이주 전부터 원주민 거주 → 16세기 말 영국인이 식민 지배·개척 → 유럽 각지 이민자 유입, 유럽인이 아프리카에서 흑인 노예 이주 → 오늘날 히스패닉 유입(독자적 문화), 아시아 등에서 경제적 이유로 이주민 유입. (앵글로 = 앵글로 색슨족에서, 라틴 = 라틴족에서 유래. 히스패닉 = 에스파냐어를 모국어로 쓰며 미국에 거주하는 라틴 아메리카 출신)
- **라틴 아메리카**: 마야·아스테카·잉카 문명이 발달했으나 유럽인 침입으로 대부분 파괴 → 16세기부터 에스파냐인이 브라질을 제외한 대부분 지역, 포르투갈인이 브라질을 식민 지배 → 유럽인이 흑인을 노예로 이주시켜 부족한 노동력 보충 → 원주민, 유럽계, 아프리카계, 혼혈인 등으로 구성.
- 로스앤젤레스 사례 [p96]: 한인 거주 지역(한인 식품점·세탁소), 1781년 에스파냐인이 정착한 멕시코 음식·공예품 거리, 일본계 이민자 거리(일본 캐릭터·일식). 프리다 칼로 「버스」(1929) = 다양한 민족·인종 [p97].

### 문화 [p98~99]
- **문화 혼종성** = 기존 문화와 외래문화가 만나 기존 문화 정체성이 약화되거나, 두 문화가 섞여 새 문화가 만들어지는 현상. 아메리카는 원주민·유럽계·아프리카계 문화가 혼합된 독특한 문화.
- 사례: 과달루페 성모상(멕시코, 가톨릭 도입 과정에서 피부색 변화), 탱고(아프리카 춤·리듬 + 유럽 악기), 햄버거(독일인의 함부르크 스테이크 변형), 리우 카니발(크리스트교 사순절 + 원주민 전통 + 아프리카 타악기 리듬·춤), 야구, 재즈·탱고·힙합(유럽·아프리카 문화 + 아메리카 문화). 힙합 = 1970년대 후반 뉴욕 빈민가의 흑인·히스패닉 청소년 [p91].
- 아메리카 문화는 세계로 전파되어 새 문화 형성에 영향을 준다(「방해」가 아님) [p99].

## 3. 아메리카의 초국적 기업 (p.100~103)

### 의미·발달 배경·특징 [p101]
- 초국적 기업 = 본사가 있는 국가를 포함해 해외 여러 국가에 자회사·지사·연구소·생산 공장 등을 운영하며 전 세계를 대상으로 생산·판매하는 기업. 농업·제조업뿐 아니라 서비스업(OTT 등)에서도 발달.
- 발달 배경: 교통·통신의 발달, 세계 무역 기구(WTO)의 등장, 자유 무역 협정(FTA)의 확대(= 수입품 관세를 없애거나 낮추는 협정). 미국에 많고, 브라질·멕시코에서도 성장.
- **공간적 분업**(경영 효율·이윤 극대화): 본사 → 정보·자본 확보 유리한 지역 / 연구소 → 고급 인력 많은 지역 / 생산 공장 → 지가·임금이 싸고 시장과 가까운 지역(고도 기술 공장은 고급 인력 지역에도). 본사에 권한이 집중되지 않고 자회사가 동등한 지위로 수평 연결.

### 입지·이전과 지역 변화 [p102~103]
- 해외 이전 까닭: 생산 비용 절감, 판매 시장 확보(수요 많은 국가), 세금 혜택·정부 지원 등 유리한 조건. 예: 멕시코 = 소비 시장이 큰 미국과 가깝고 저임금 노동력 풍부 → 자동차 공장 입지.
- 들어선 지역: 산업 단지 조성·일자리·기술 이전·관련 산업 발달·경제 활성화 / 환경 오염. 빠져나간 지역: 산업 기반 약화·실업률 상승·인구 감소·경제 침체. 사례: 디트로이트(1950년대 최대 공업 도시 → 20세기 후반 공장이 낮은 임금을 찾아 멕시코 등으로 이전 → 침체 → 정부·시의 기업 유치 정책으로 재도약 시도) [p103].
- 실리콘 밸리 [p102]: 샌프란시스코·새너제이 일대의 첨단 기술 연구 단지. 성장 까닭 = 주변 대학의 인재 배출, 기업과 학교의 협력, 미국의 큰 시장. 부작용 = 집값·임대료 급등, 교통 혼잡. (『YTN사이언스』 2023. 8. 14.)

## 불일치 · 원문 대조 못 한 곳
- 교과서 내부 불일치(출제 안 함): p.105 평가하기 4번 게시판의 '지유'(햄버거 = 「에스파냐인」이 먹던 …)와 '은우'(리우 카니발 = 「아메리카 원주민」의 타악기 리듬)는 p.98(「독일인들」)·p.99(「아프리카의」 타악기)와 다르다. 교사용 정답(아윤, 지호)과는 맞다.
- 지도서 p.181 대단원 평가 06번 〈보기〉 ㄹ은 「포르투갈인이 브라질을 비롯한 대부분의 지역」으로 오기(지도서 해설은 에스파냐가 대부분 지역). 교과서 p.97은 에스파냐 = 브라질 제외 대부분, 포르투갈 = 브라질 → 교과서대로 출제.
- 교사용·지도서에만 있고 교과서 본문에 없는 내용은 정답 근거로 쓰지 않았다(흑인의 지역별 분포, 멕시코시티·쿠스코 등이 고산 도시라는 설명, 마킬라도라, 아마존 개발 갈등, 우유니 소금 사막의 생성 원인, 샌프란시스코 도시 설명).
- p.97 민족·인종 분포도 수치와 p.90~91 지도 속 글자는 깨져 읽지 못했다 → 구성 비율 그래프는 가상 국가 모식도로 새로 만들었고, 도시 위치는 일반 지리 위치(교사용 쪽 설명과 일치)를 따랐다.
- 수치(2,200m, 50%, 200여·130여, 1781년, 1970년대 후반)는 본문에서 확인했다. 연도·인구 정확 값 단답은 출제하지 않았다.
