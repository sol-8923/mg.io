# 7. 입체도형의 성질 — 핵심 정리 (동아출판 중학 수학 1, 교과서 208–237쪽)

> 출처 표기 [pN] = 교과서 인쇄 쪽(PDF 쪽과 같음). 문장은 요약·재구성했고, 정의 용어는 교과서 표기를 따른다.

## 단원 개요
다면체와 정다면체 → 회전체 → 기둥과 뿔의 겉넓이 → 기둥과 뿔의 부피 → 구의 겉넓이와 부피 순서로 배운다. [p208–233]

## 핵심 개념
### 7.1 다면체
- 다면체: 다각형인 면으로만 둘러싸인 입체도형(각기둥, 각뿔 등). 면이 4개, 5개, 6개, …이면 각각 사면체, 오면체, 육면체, … [p210] (원기둥·원뿔은 곡면이 있어 다면체가 아니다 [p210 질문])
- 다면체의 면·모서리·꼭짓점: 다각형=면, 다각형의 변=모서리, 다각형의 꼭짓점=꼭짓점 [p210]
- 각뿔대: 각뿔을 밑면에 평행한 평면으로 잘랐을 때 각뿔이 아닌 쪽. 평행한 두 면이 밑면, 나머지가 옆면이고 옆면은 사다리꼴, 높이는 두 밑면에 수직인 선분의 길이. 밑면의 모양에 따라 삼각뿔대, 사각뿔대, … [p211]
- 단면: 입체도형을 평면으로 자를 때 생기는 면. 각뿔을 밑면에 평행하게 자른 단면은 밑면과 모양이 같고 크기만 작은 다각형이다(교과서 문제 3) [p211]
- 정다면체: 모든 면이 합동인 정다각형이고 각 꼭짓점에 모인 면의 개수가 같은 다면체. 정사면체·정육면체·정팔면체·정십이면체·정이십면체 다섯 가지뿐 [p212]
- 면의 모양에 따른 분류: 정삼각형 – 정사면체·정팔면체·정이십면체 / 정사각형 – 정육면체 / 정오각형 – 정십이면체 [p213]
- 한 꼭짓점에 모인 면의 개수: 정사면체 3·정육면체 3·정팔면체 4·정십이면체 3·정이십면체 5 [p212~213 관찰 활동, 해설 표 확인]. 면의 개수: 4·6·8·12·20.
- 면의 모양이 정육각형인 정다면체가 없는 이유: 한 꼭짓점에 정육각형 3개가 모이면 모인 각의 합이 120°×3=360°가 되어 입체를 만들 수 없다 [p213 질문의 해설].
- (교과서 밖 참고) 꼭짓점−모서리+면=2 (오일러 관계)는 교과서에 없다. 슬라이드 4번에 "교과서 밖 참고"로만 표시해 두었다.
- 각기둥·각뿔·각뿔대의 개수(n각형 기준, 교과서 p214 도전 문제를 일반화한 정리): 각기둥 면 n+2·모서리 3n·꼭짓점 2n, 각뿔 면 n+1·모서리 2n·꼭짓점 n+1, 각뿔대 면 n+2·모서리 3n·꼭짓점 2n.

### 7.2 회전체
- 회전체: 평면도형을 한 직선을 축으로 하여 1회전 시킬 때 생기는 입체도형, 그 직선이 회전축. 직사각형→원기둥, 직각삼각형→원뿔, 반원→구 [p215]
- 원뿔대: 원뿔을 밑면에 평행한 평면으로 자를 때 원뿔이 아닌 쪽 [p217]
- 회전체의 성질 [p216]: ① 회전축에 수직인 평면으로 자른 단면은 원 ② 회전축을 포함하는 평면으로 자른 단면은 모두 합동이고 회전축을 대칭축으로 하는 선대칭도형

### 7.3 기둥과 뿔의 겉넓이
- 밑넓이: 한 밑면의 넓이, 옆넓이: 옆면 전체의 넓이 [p219]
- (기둥의 겉넓이) = (밑넓이)×2 + (옆넓이) [p220]
- (뿔의 겉넓이) = (밑넓이) + (옆넓이). 원뿔의 옆면은 부채꼴이고 넓이는 ½×(모선, 꼭짓점과 밑면의 원 위의 한 점을 이은 선분)×(밑면의 둘레) [p221]
- 원기둥의 옆면은 직사각형(가로=밑면의 둘레), 각기둥은 직사각형 여러 개 [p220]

### 7.4 기둥과 뿔의 부피
- (기둥의 부피) = (밑넓이)×(높이) [p224–225]
- (뿔의 부피) = ⅓×(밑넓이)×(높이): 밑면이 합동이고 높이가 같은 기둥 부피의 ⅓ [p226]

### 7.5 구의 겉넓이와 부피
- (구의 겉넓이) = 4πr², 구와 반지름이 같은 원의 넓이의 4배 [p229]
- (구의 부피) = 4/3 πr³ = 밑면의 반지름 r·높이 2r인 원기둥 부피의 ⅔ [p230]
- 반구는 구의 ½: 겉넓이 = 곡면 2πr² + 밑면 πr² = 3πr² (교과서 p229 문제 1(2)의 방식)
- 반지름이 k배가 되면 구의 겉넓이는 k²배, 부피는 k³배가 된다(공식 4πr², 4/3πr³에서 r만 k배로 바꾸어 확인) [p229–230]

## 꼭 외울 것
1. 정다면체 5종의 면의 모양과 한 꼭짓점에 모인 면의 개수 [p212–213]
2. 회전체의 두 가지 단면 성질 [p216]
3. 겉넓이: 기둥 = 밑넓이×2+옆넓이 / 뿔 = 밑넓이+옆넓이 / 구 = 4πr² [p220–229]
4. 부피: 기둥 = 밑넓이×높이 / 뿔 = ⅓×밑넓이×높이 / 구 = 4/3 πr³ [p225–230]

## 헷갈리기 쉬운 것
| 비교 | 기둥 | 뿔 | 뿔대 |
|---|---|---|---|
| 옆면의 모양 | 직사각형 | 삼각형 | 사다리꼴 [p211] |
| 모서리 수(n각형) | 3n | 2n | 3n |
| 회전체 | 원기둥(직사각형) | 원뿔(직각삼각형) | 원뿔대(사다리꼴) |

## 자주 하는 오해
- 원기둥·원뿔도 다면체라고 생각한다 → 곡면이 있어 다면체가 아니다 [p210].
- 회전축을 포함하는 단면과 수직인 단면을 바꿔 쓴다 → 수직은 원, 포함은 합동인 선대칭도형 [p216].
- 뿔의 부피에서 ⅓을 빠뜨린다, 구의 부피에서 4/3를 빠뜨린다 [p226, p230].
- 원뿔 옆넓이를 구할 때 높이를 모선 대신 쓴다 → 모선의 길이를 써야 한다 [p221].
