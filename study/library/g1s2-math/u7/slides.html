7.1 다면체

다면체와 각뿔대 p210~211

다면체

  • 다각형인 면으로만 둘러싸인 입체도형 (각기둥, 각뿔 등)
  • 면이 4개, 5개, 6개, …이면 각각 사면체, 오면체, 육면체, …
  • 다각형 = 면, 다각형의 변 = 모서리, 다각형의 꼭짓점 = 꼭짓점
주의 원기둥·원뿔은 곡면이 있어 다면체가 아니다.

각뿔대

  • 각뿔을 밑면에 평행한 평면으로 잘랐을 때 각뿔이 아닌 쪽
  • 평행한 두 면 = 밑면, 나머지 = 옆면(사다리꼴)
  • 높이 : 두 밑면에 수직인 선분의 길이
  • 밑면의 모양에 따라 삼각뿔대, 사각뿔대, …

단면

각뿔을 밑면에 평행하게 자른 단면은 밑면과 모양이 같고 크기만 작은 다각형.

이해하는 방법

  • 각기둥 : 밑면 2개 + 옆면 n개 → 면 n+2
  • 각뿔 : 밑면 1개 + 옆면 n개 → 면 n+1
  • 각뿔대는 각기둥과 면·모서리·꼭짓점의 수가 같다.

검산 (모서리·꼭짓점·면 관계) 교과서 밖 참고

각기둥 : 2n − 3n + (n+2) = 2
각뿔 : (n+1) − 2n + (n+1) = 2

(꼭짓점 − 모서리 + 면 = 2 로 맞는지 확인하는 용도. 교과서에는 나오지 않는 내용이라 시험에 나오지 않아도 괜찮아요.)

회전체와 단면의 성질 p215~217

회전체

평면도형을 한 직선을 축으로 1회전 시킬 때 생기는 입체도형. 그 직선이 회전축.

직사각형원기둥
직각삼각형원뿔
반원구
사다리꼴원뿔대

원뿔대 : 원뿔을 밑면에 평행한 평면으로 자를 때 원뿔이 아닌 쪽.

회전체의 성질 (p216)

  • ①회전축에 수직인 평면으로 자른 단면은 원
  • ②회전축을 포함하는 평면으로 자른 단면은 모두 합동이고, 회전축을 대칭축으로 하는 선대칭도형
헷갈리지 말 것 수직 → 원 / 포함 → 합동인 선대칭도형. 서로 바꿔 쓰지 않는다.

7.3 기둥과 뿔의 겉넓이

겉넓이 = 밑넓이 + 옆넓이 p219~221

공식

기둥 = (밑넓이)×2 + (옆넓이)
뿔 = (밑넓이) + (옆넓이)

밑넓이 = 한 밑면의 넓이, 옆넓이 = 옆면 전체의 넓이

옆면의 모양

  • 원기둥의 옆면 : 직사각형 (가로 = 밑면의 둘레), 각기둥은 직사각형 여러 개
  • 원뿔의 옆면 : 부채꼴, 옆넓이 = ½ × 모선 × (밑면의 둘레)
  • 모선 : 꼭짓점과 밑면의 원 위의 한 점을 이은 선분

원기둥의 전개도 : 밑면 2개 + 직사각형 1개 → 겉넓이 = 2πr² + (밑면의 둘레)×(높이)

오해 주의 원뿔의 옆넓이를 구할 때 높이를 모선 대신 쓰지 않는다. 모선의 길이를 써야 한다.

7.4 기둥과 뿔의 부피

기둥과 뿔의 부피 p224~226

기둥의 부피

(밑넓이) × (높이)

뿔의 부피

⅓ × (밑넓이) × (높이)

뿔과 기둥의 관계

뿔의 부피는 밑면이 합동이고 높이가 같은 기둥 부피의 ⅓이다.

기둥의 부피뿔의 부피
V⅓ V

자주 하는 실수

  • 뿔의 부피에서 ⅓을 빠뜨린다.
  • 겉넓이는 밑넓이를 기둥에서 2번, 뿔에서 1번 더한다.

7.5 구의 겉넓이와 부피

구의 겉넓이와 부피 p229~230

겉넓이

4πr²

구와 반지름이 같은 원의 넓이(πr²)의 4배

반구의 겉넓이

곡면 2πr² + 밑면 πr² = 3πr²

부피

4/3 πr³

밑면의 반지름 r, 높이 2r인 원기둥 부피의 ⅔

검산 : 원기둥 πr²×2r = 2πr³ → 2πr³ × ⅔ = 4/3 πr³

반지름이 k배가 되면

공식에서 r만 k배로 바꾸어 확인한다 → 겉넓이는 k²배, 부피는 k³배 (p229~230)

오해 주의 구의 부피에서 4/3을 빠뜨리지 않는다.
