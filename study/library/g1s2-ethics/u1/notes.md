# 타인과의 관계 — 핵심 정리 (1학년 2학기 도덕 샘플)

## 단원 개요
가족·친구·이웃과 맺는 관계에서 필요한 덕목(효, 우정, 공감, 관용, 용서, 이타주의)과 인터넷·학교 생활의 폭력 문제를 배운다. 개념을 구분하고 사례에 적용하는 것이 핵심이다.

## 핵심 개념
### 가족과 친구 (출처: 「효」「우정」)
- 효: 부모를 봉양하는 마음. 공자는 봉양뿐 아니라 공경하는 마음을 강조
- 묵자: 혈연 중심 사랑이 싸움과 혼란을 부른다고 비판 / 노자: 인위적 인의 강조의 결과로 효가 나타났다고 비판
- 현대: 2022년 가사소송법 개정으로 학대당한 미성년 자녀가 부모 친권 박탈 청구 가능. 부모가 의무를 이행하지 않으면 자식의 의무도 달라질 수 있음
- 우정: 친구 사이의 정신적 유대감. 지인보다 강한 관계. 정기적 교류·솔직한 소통·세심한 경청으로 유지

### 공감·관용·용서·이타주의 (출처: 「공감」「관용」「용서」「이타주의」)
- 공감: 상대방 입장에서 이해. 인지적 공감/감정적 공감. 가치 중립적
- 관용: 의견이 다를 때 논쟁은 하되 물리적 폭력에 호소하지 않음. 틀렸다는 이유로 표현을 봉쇄하지 않음
- 용서: 복수 같은 부정적 정서를 버리는 자발적 과정. 용납·사면·화해·망각과 다름. 용서하는 사람이 더 행복하고 건강
- 이타주의: 나보다 남을 먼저 생각. 이기주의와 반대. 순수한 이타주의는 보상을 바라지 않음

### 폭력과 인터넷 예절 (출처: 「학교 폭력」「사이버 폭력」「네티켓」)
- 학교 폭력: 폭행·협박·따돌림·모욕·사이버 따돌림 등. 따돌림을 제외하면 형사 범죄
- 사이버 폭력: 비대면성·익명성·영구성·확산성
- 네티켓: 네트워크 + 에티켓. 상대방도 사람, 사생활 존중, 절제된 감정으로 논쟁, 타인의 실수 용서

## 꼭 외울 것
- 공자 = 공경 / 묵자 = 혈연 중심 비판
- 용서 ≠ 용납 / 관용 = 논쟁 O 폭력 X
- 네티켓 = 네트워크 + 에티켓

## 시험 포인트
- 개념 구분형: 용서/용납, 인지적/감정적 공감, 이타주의/이기주의
- 사례 적용형: 관용적 토론, 우정 유지, 사이버 폭력
- 서술형: 조건 낱말(입장, 폭력·토론, 복수, 상대방)을 쓰는 사례 서술
