대단원: Ⅱ 타인과의 관계

# Ⅱ-3 가상공간과 타인 존중 — 핵심 정리 (도덕 ① 해냄에듀, 쪽 = 인쇄쪽 = PDF쪽 106–121)

> 근거: 학생용 교과서 `[pN]`. 교사용 교과서·지도서는 정답·용어 확인용으로만 대조했다(핵심 용어에서 불일치 없음).

## 01 가상공간은 어떤 곳일까?
- **가상공간의 의미** [p106]: 정보 통신망을 바탕으로 디지털 정보를 공유·교환하는 가상의 활동 공간. 일상생활과 활발한 의사소통이 이루어지고 새로운 공동체·문화가 만들어지는 곳.
- **우리 삶과의 관계** [p106]: 스마트폰 등장 이후 언제 어디서든 접속 → 삶의 영역 확대, 현실과 가상공간의 경계가 모호해짐. 지나치게 몰입하면 현실의 자아와 가상공간의 자아 사이에서 혼란, 현실보다 가상공간에 의존할 수 있음 → 두 공간을 **균형 있게** 대하는 자세.
- **가상공간의 특징 세 가지** [p108]
  - 시공간 제약 극복: 시간·장소와 상관없이 원격 수업·재택근무·원격 진료, 멀리 있는 사람과 실시간 정보 공유.
  - 익명성: 자신이 누구인지 밝히지 않아도 되는 속성. 나이·사회적 지위와 관계없이 평등하게 소통.
  - 개방성: 누구에게나 열려 있어 많은 사람이 정보를 이용하고 누구나 정보를 생산·유통. 현실에서 만나기 어려운 사람과 인간관계.
- **가상공간이 가져온 변화** [p109]: 가상 현실(VR) 기술로 재난 대비 훈련·치매 환자 인지 능력 개선 등 현실에서 불가능한 경험. 랜선 친구처럼 가상공간의 인간관계가 확대.

## 02 가상공간에서 도덕적 책임이 필요한 이유는 무엇일까?
- **도덕 문제의 종류** [p110–111]
  - 사이버 폭력: 인터넷상에서 언어·영상 등으로 상대방에게 피해·불쾌감을 주는 행위. 사이버 스토킹(원하지 않는 접근을 계속 시도), 사이버 성폭력, 사이버 괴롭힘(집단 따돌림·집요한 괴롭힘), 비속어·악성 댓글 같은 언어폭력.
  - 사생활 침해: 개인 정보·사생활 정보 유출, 다른 사람의 사진을 허락 없이 올리는 행위. 개인 정보 유출은 금융 사기 등에 악용, 동의 없는 공개는 명예 훼손·자유로운 활동 방해.
  - 거짓 정보와 편향성: 확인되지 않은 거짓 정보의 무분별한 생산·유통(딥페이크), 추천 알고리즘 때문에 정보가 편향되어 편견 강화·차별.
  - 지식 재산권 침해: 지식 재산권 = 산업·과학·문학·예술·디자인 등 지적 창조 활동에서 발생하는 모든 권리. 허락 없이 글·그림·음악·영상을 쓰면 침해.
- **원인** [p112]: 신분을 밝히지 않아도 돼 책임을 피할 수 있다고 생각해 무책임해짐 / 얼굴을 마주하지 않아 피해에 무감각해짐 / 누구나 정보를 만들고 퍼뜨려 잘못된 내용이 섞일 가능성.
- **도덕적 책임이 필요한 이유** [p112]: 이용자도 현실에서 활동하는 인격체 / 잘못된 말·행동이 현실까지 영향 / 정보가 빠르게 퍼져 피해 범위가 넓고, 삭제·수정이 어려워 피해가 오래 지속 / 가해자도 결과에서 벗어나기 어려움.

## 03 가상공간을 올바르게 활용하려면 어떻게 해야 할까?
- **가상공간에서 필요한 도덕 원칙** [p114]: 존중(모든 사람의 인격과 권리를 소중히 여김), 책임(결과를 예측하며 행동하고 결과에 책임), 해악 금지(다른 사람에게 피해를 주지 않음), 정의(모두를 공정하게 대하고 올바름을 추구).
- **인공지능 윤리 기준 원칙(잠깐 알아볼까요)** [p114]: 인간 존엄성 원칙(생명·건강에 해가 되지 않는 범위), 사회의 공공선 원칙(사회적 약자·취약 계층의 접근성 보장, 인류 보편적 복지 향상), 기술의 합목적성 원칙(인류의 삶에 필요한 도구라는 목적에 부합, 과정도 윤리적).
- **올바르게 활용하기 위한 태도** [p116]: 가상공간과 삶을 단절하는 것은 올바른 해결책이라 말하기 어렵다.
  - 타인 존중: 예의, 이해와 공감, 생각이 다른 사람을 혐오·배척하지 않기, 창작물 존중·지식 재산권 보호.
  - 도덕적 판단력: 말·행동에 차별·편견이 담겼는지 검토, 폭력에 동조하고 있지 않은지 점검, 영향과 결과 예측.
  - 디지털 문해력: 정보를 비판적으로 이해하고 생산하는 능력. 정보의 소비자이자 생산자 → 잘못된 정보를 만들거나 공유하지 않기, 바로잡고 선한 영향을 주는 정보 생산.
  - 윤리적인 인공지능 활용: 타인의 권리·자유 침해 금지, 피해 주지 않기. 사생활 침해·지적 재산권 침해·정보의 편향성 주의.
- **특집: 디지털 문해력** [p118–119]
  - 미디어 정보에는 제작자의 관점이 개입, 일부만 보면 사실과 다르게 파악 [p118]. 자극적 영상은 조회 수(곧 돈)를 노려 사실 확인 없이 만들어지기도 함 [p118].
  - 확증 편향: 믿고 싶지 않은 사실을 의심하고, 한번 옳다고 믿은 생각을 바꾸지 않으려는 경향. 정보 통신 기술과 만나 거짓 정보가 더 빨리 퍼짐 [p119].
  - 정보를 소비할 때: 정확성 검토 / 출처 확인 / 균형성 검토. 정보를 만들 때: 결과 예상 / 사실·불법 여부 확인 / 저작권 확인 / 차별·편견 확인 [p119].
- **단원 탐구 논술** [p120–121]: 가상공간이 현실 세계를 완벽히 대체할 수 있는가(자신의 입장 논술) — **의견을 묻는 활동이라 문제 은행에서 정답을 정해 출제하지 않는다.**

## 불일치·출제하지 않은 것
- 교과서·교사용·지도서의 핵심 용어(가상공간의 특징, 도덕 문제 종류, 원칙, 태도)는 서로 달라 보이는 곳 없음.
- 단원 탐구 논술(가상공간의 현실 대체 가능성)과 '이것도 가상공간에서 일어나는 도덕 문제라고?' 토의(p111)는 의견·가치 판단이므로 출제하지 않는다.
- p118 특집의 실제 사건(고3 학생 사례)은 민감하고 실제 인물 관련이라 쓰지 않는다.

## 시험 포인트
- 가상공간의 특징 3가지(시공간 제약 극복·익명성·개방성)를 〈보기〉 사례로 구분 — 기출(2025 기말)에 익명성이 나옴.
- 사이버 폭력의 종류(스토킹·성폭력·괴롭힘·언어폭력)와 도덕 문제 4종(사이버 폭력·사생활 침해·거짓 정보와 편향성·지식 재산권 침해) 구분.
- 도덕 문제의 원인(책임을 피할 수 있다는 생각·무감각)과 도덕적 책임이 필요한 이유(인격체·현실 영향·빠른 확산과 삭제 곤란).
- 가상공간에서 필요한 도덕 원칙 4가지(존중·책임·해악 금지·정의), 인공지능 윤리 기준 3원칙 — 기출에 나옴.
- 올바른 활용 태도 4가지(타인 존중·도덕적 판단력·디지털 문해력·윤리적 인공지능 활용), 확증 편향, 정보를 읽고 쓰는 방법.
