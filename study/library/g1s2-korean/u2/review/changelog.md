# 2단원 검수 이력
- 라운드 1: 형식·종합 반려(Q06 발문이 밑줄을 지칭하나 지문에 표시 없음 / S03-b 지문이 Q08-a 정답을 노출 / Q10-a·S03-b 사례 중복), 내용 반려(S04-b 모범 답안이 두 문장), 오답풀이 PASS.
- 수정: Q06 발문을 단어 직접 지목으로 변경, '헛-' 뜻 '보람 없는', S03-a 출처 단정 삭제, S03-b 지문을 '웰빙→참살이'로 교체, S04-b 모범 답안 한 문장화, Q10-a 해설의 '각자 어근' 표현 수정, S03-b tip 정리.
- 라운드 2: 형식·내용·종합·오답풀이 4중 PASS(만장일치). 종합 검수의 난이도 지적(S04 '상'이 쉬움, Q10-b·Q14-b 소거 가능, Q16-b 오답 약함)은 기록만(예외 규칙).
- 기출 비율: past-exam 프로필(객관식 3점 중심, 총 65점→100점 환산). 요약 슬라이드는 책 마지막에 일괄 제작.
