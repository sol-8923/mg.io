# 수학 요약 슬라이드 스타일

`library/g1s2-math/u*/slides.html` 전용. 다른 과목은 `slide-style.md`(칠판 + 황동)를 그대로 쓴다.

## 메타포: 고슴도치 모눈 노트
- 실제 표지(`library/g1s2-math/cover.png`, 동아출판 중학 수학 1)에서 딴 요소: 주황 바탕, 벽돌빛 붉은 둥근 제목 글자, 크림색 고슴도치, 허공에 떠 있는 손글씨 식(`3x+1=2`, `x+a=b`), 반짝이 별.
- 수학 교과서다운 요소를 더함: 모눈 노트(왼쪽 바인딩 구멍 + 빨간 여백선), 좌표평면, 각도기, 자와 연필.
- 원칙: 표지의 주황·붉은 색감은 유지하고, 본문은 밝은 바탕 + 어두운 글자로 읽기 편하게 한다.

## 글꼴 (Google Fonts)
- 제목 h1·h2·h3·수식 박스·번호: Jua (표지의 둥근 제목체와 비슷)
- kicker·표지 손글씨 장식: Nanum Pen Script (제목 위 한 줄에만)
- 본문·표: Noto Sans KR
- Gowun Dodum은 대체 글꼴로만 지정

## 장식 규칙
- 본문 최소 27px(무대 기준) 유지, 장식은 본문 영역 밖에만 둔다: 왼쪽 80px 바인딩 띠, 오른쪽 위 자와 연필(y 18~58), 오른쪽 아래 쪽번호 원.
- 카드는 흰 바탕 + 주황 테두리 + 오프셋 그림자. `.warn` 카드는 붉은 점선 + 느낌표 아이콘.
- SVG 그림 카드는 연한 남색 모눈을 깔고, SVG 글자는 흰 테두리(paint-order)로 선과 겹쳐도 읽히게 한다.
- 줄바꿈: `.slide, td, .card`에 `word-break: keep-all; overflow-wrap: break-word`(한글을 음절 중간에서 끊지 않음).
- 세로 배치: 일반 슬라이드는 제목 아래 본문 블록을 세로 가운데에 놓고(`h2 + *`, 마지막 블록의 `margin: auto`), 내용이 적으면 슬라이드별 `--z`(1~1.4) 값으로 본문을 확대한다(`zoom`). `--z`는 본문 높이를 재서 정한 값이며 모바일에서는 무시한다.
- 용어 목록: `p.terms`(2열) 안에 `span.tm`(용어 굵게 + 설명), 기존 ` · ` 구분 글자는 `span.sep`으로 숨김.
- 마지막 `핵심 암기` 슬라이드(`.core`): 항목마다 번호 붙은 카드(2열, 화면 대부분을 채움, 글자 31px, 4개짜리는 `.few` 38px).
- SVG 색 대응(도형 좌표·의미는 그대로): 축·보조 `#5A4636`, 글자 `#2A2018`, 주선 `#C2410C`, 보조선 `#17766A`, 점선 `#2F5DA8`, 면 채움 `rgba(245,138,75,.25)`.

## 표지
- 모눈 위 큰 주황 원 안에 단원 소재 그림, 아래쪽 각도기(진행 표시 축과 겹치지 않게 x 910~1310), 오른쪽 아래 고슴도치(SVG), 손글씨 식과 별. 고슴도치·주황 테마는 단원 공통.
- 단원별 그림: 4단원 좌표평면(y=ax), 5단원 각의 이등분선 작도(컴퍼스 호), 6단원 삼각형(내각·외각 표시)과 원·부채꼴, 7단원 정육면체·원뿔·구.
- 모바일은 `.deco-s`(그림)와 `.deco-h`(고슴도치)를 작게 보여 준다.
- 제목 112px 벽돌색, 강조어는 남색 + 주황 형광펜 줄.

## 진행 표시
- 화면 아래 x축(화살표 + 눈금)을 따라 붉은 점이 이동하고, 점 옆에 `(현재쪽, 0)` 좌표를 표시. 지나간 눈금은 주황.
- 컨트롤 바(하단 중앙)와 겹치지 않도록 폭 620px, 화살촉은 마지막 점에서 떨어지게 선을 44px 더 뻗는다. 마지막 쪽에서는 좌표 라벨을 점 왼쪽에 둔다(`.co.end`). 모바일·인쇄에서는 숨긴다.
