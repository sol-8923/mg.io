# 국어 요약 슬라이드 스타일

`library/g1s2-korean/u1~u4/slides.html`에 쓰는 과목 전용 스타일. 공통 규칙(1920x1080 무대, 최소 글자 24px, 모바일 820px 이하 세로 카드)은 `slide-style.md`를 따르고, 색·모양·장식만 이 문서로 대체한다.

## 메타포: 과자 봉지 속 놀이공원
교과서(비상 국어 1-2) 표지: 파란 과자 봉지 비닐 포장 구멍으로 파스텔 놀이공원(회전목마, 풍선, 대관람차, 쿠키 캐릭터)이 보이고 노란 굵은 손글씨 제목.
- 표지 슬라이드 = 봉지 앞면. 코발트 파랑 바탕, 윗면 접힌 주름(세로 줄무늬), 비닐 광택 다각형, 구멍 모양(크림 테두리)의 놀이공원 SVG, 노란 제목(남색 외곽선 그림자).
- 본문 슬라이드 = 봉지 안쪽. 크림 바탕을 파란 봉지 테두리(둥근 안쪽 모서리)가 감싸고 윗변에 실링 주름.
- 슬라이드 번호 = 노란 놀이공원 티켓("TICKET No. n", 양옆 홈). 진행 표시 = 컨트롤 막대의 풍선(분홍 막대 끝에 노란 풍선, `#count` 변화를 따라감).

## 색 (`:root` 변수)
| 변수 | 값 | 용도 |
|---|---|---|
| `--sky` | `#3a86d9` | 봉지 테두리, hl 카드 테두리 |
| `--cobalt` | `#1d5fd1` | h3, 표 머리(흰 글자), SVG 선 |
| `--navy` | `#14306e` | h2, 표지 그림자, 티켓 글자 |
| `--cream` | `#fff8e6` | 슬라이드 바탕 |
| `--card` / `--card-hl` / `--card-warn` | `#fff` / `#eaf4ff` / `#fff1ec` | 카드 바탕 (일반 / 강조 / 주의) |
| `--ink` / `--ink-dim` | `#1b2a4a` / `#50608a` | 본문 / 보조 글자 |
| `--pink` | `#b81f57` | 강조(b), 순서 번호, 통계 숫자 (노랑 형광펜 밑줄과 함께) |
| `--pink-soft`, `--yellow`, `--mint` | `#ff7aa8`, `#ffd84d`, `#52c9a0` | 목록 풍선 점, 태그, 장식 |
| `--warn` | `#b3332a` | 오해·주의 제목 |
- 대비: 본문 `--ink` on 크림 약 14:1, 표 머리 흰 글자 on `--cobalt` 약 6:1, 강조 `--pink` on 흰/연파랑 약 6:1 (AA 이상).
- SVG 도식은 변수를 못 쓰므로 선 `#1d5fd1`, 상자 채움 `#e6f2ff`를 직접 쓴다.

## 글꼴 (Google Fonts)
- 제목·표 머리·번호: Jua (둥글고 굵은 손글씨풍, 굵기 400 하나라 `font-weight: 400`)
- 본문: Gowun Dodum
- 대체: 'Malgun Gothic', sans-serif

## 장식 규칙
- 모양: 둥근 모서리(카드 28px), 카드 아래 단색 그림자(스티커 느낌), 목록 점은 광택 있는 풍선(분홍/노랑/민트 순환), 순서 카드는 5색 과자 색(민트·노랑·분홍·하늘·연보라) 순환.
- 장식은 가장자리에만: 오른쪽 위 풍선(96px), 왼쪽 아래 색종이. 본문 영역·표·카드 위에 겹치지 않게 한다.
- 표지: 왼쪽 제목 영역(폭 840px)과 오른쪽 구멍(940x800)을 나눈다. 제목은 `word-break: keep-all`, `text-wrap: balance`로 단어 단위 줄바꿈.
- 모바일(820px 이하 세로): 봉지 테두리 카드를 세로로 쌓고 표지는 제목 → 놀이공원 순서, 컨트롤·무대 장식은 숨김.
- 슬라이드 본문 내용(텍스트·표·사실)은 바꾸지 않는다. 한 슬라이드가 넘치면(콘텐츠가 아래 티켓·컨트롤 위까지 닿으면) 슬라이드를 나눈다.

## 화면 검수 보정 (2차)
- 줄바꿈: `.slide`에 `word-break: keep-all; overflow-wrap: break-word` (글자 단위 줄바꿈 방지).
- 세로 채우기: 데스크톱은 본문 묶음을 세로 중앙에 두고(`h2 + *`, `*:has(+ .pg)`의 auto 여백), 슬라이드 끝 스크립트가 내용이 적은 쪽에 `zoom`(최대 1.2)을 걸고, 그래도 비면 `.roomy`(카드 여백·간격 확대, 최대 1.25)를 켠다. 모바일은 적용하지 않는다.
- 2열 카드(`.g2`)는 `align-items: start`(짧은 카드가 억지로 늘어나지 않음).
- 진행 표시: `.trk` 150px 고정, `#count` min-width 64px, 풍선은 막대 폭 안(`calc(11px + (100% - 22px) * 비율)`).
- 표지: 구멍 `top:150px`(컨트롤과 간격), 제목은 2줄 높이 칸에서 세로 중앙(부제 위치 통일), 구멍 옆 반투명 다각형 2개 제거.
- 머리: `h2 { max-width: 1640px }`(오른쪽 위 풍선과 겹침 방지). 모바일 다이어그램(`svg.dia`)은 min-width 1100px + 가로 스크롤.
- 표 머리 `A / B`는 `앞쪽 항목 / 뒤쪽 항목`(구분 칸의 `vs` 앞·뒤)으로 바꿨다.

## 검수 정리 v3 (재검수 B급)
- 4개 슬라이드(`u1~u4/slides.html`)의 `<style>` 끝에 `/* ===== 검수 정리 v3 ===== */` 블록을 공통으로 둔다.
- 줄바꿈: 가운뎃점으로 이은 짧은 구절(12자 이하), `단어 ·`, `용어 :`, `A /`, 숫자+단위, `)로`처럼 닫는 괄호+조사는 `<span class="nw">`로 묶어 줄 중간에서 끊지 않는다(`span.nw { white-space: nowrap }`, 표의 `table.t.nw`와 구분). 12자 초과 구절은 가운뎃점 앞뒤 3글자만 묶는다. 본문 글자는 바꾸지 않고 태그만 추가한다. `p, li, td, th, .card`에 `text-wrap: pretty`.
- 컨트롤: `#count`를 `width: 76px`, `tabular-nums`로 고정해 두 자리 쪽수에서도 막대가 흔들리지 않는다.
- 모바일: 가로 스크롤 다이어그램 래퍼(`.dia-wrap`) 위에 `← 옆으로 밀어서 보기 →` 안내(`::before`, 데스크톱은 없음). 카드 안 인라인 확대 글자(30~34px)는 17px로 통일, 표 글자는 16px.
- 개별: u2 8번 안내 카드는 `.card.note`(노란 바탕·분홍 막대), u4 5번 한 줄 요약은 `.card.sum`(좌우 두 덩어리를 `nw`로 묶어 두 줄 균형), u4 15번 표/목록 비율 `1.4fr 1fr`, u3 17번 표 비율 `1.4fr 1fr` + 첫 열 20%.
