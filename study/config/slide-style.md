# 발표 자료 스타일

교과 정리 슬라이드(`drafts/.../slides.html`)에 공통으로 쓰는 스타일. 이 앱의 톤(칠판 + 황동)을 그대로 따른다.

## 이름
- 칠판 (Chalkboard Brass) — 프리셋·템플릿이 아닌 앱 톤 기반 맞춤 스타일

## 색상 (`:root` 변수)
| 변수 | 값 | 용도 |
|---|---|---|
| `--bg` | `#14301f` (짙은 칠판 녹색) | 슬라이드 배경 |
| `--bg-2` | `#1c4029` | 카드·표 머리 |
| `--ink` | `#f3ead3` (크림) | 본문 글자 |
| `--ink-dim` | `#c9c3a8` | 보조 글자 |
| `--brass` | `#c9a24b` (황동) | 포인트·강조·구분선 |
| `--warn` | `#e08a6a` | 오해·주의 표시 |

## 글꼴 (한글, Google Fonts CDN)
- 제목: Noto Serif KR (세리프)
- 본문: Noto Sans KR
- 대체 글꼴 순서: 'Malgun Gothic', serif/sans-serif

## 레이아웃 규칙
- High density / reading-first. 1920x1080 고정 무대(16:9)를 뷰포트에 맞춰 축소.
- 세로 좁은 화면(모바일 세로, 폭 820px 이하)은 읽기 편하도록 슬라이드를 세로로 쌓아 스크롤하는 카드 레이아웃으로 전환.
- 본문 최소 글자 크기 24px(무대 기준). 넘치면 슬라이드를 나눈다.
- 배포(Vercel)·PDF 변환은 하지 않는다.
