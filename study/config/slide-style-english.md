# 영어 슬라이드 스타일 (여행 엽서 · 말풍선 · 항공 노선)

영어 교과 정리 슬라이드(`library/g1s2-english/u*/slides.html`)의 과목 전용 디자인. 공통 뼈대·스타일은 v2 방식으로 `config/slide-v2/g1s2-english/`(`skeleton.html`, `base.css`)에 있고, 단원은 `docs/슬라이드-v2-규칙.md`대로 조각으로 만든다. 과학 템플릿의 구조를 그대로 쓰고 색과 장식만 영어용으로 바꿨다(2026-11-17).

## 메타포
- 슬라이드 = 여행 엽서 한 장, 카드 = 말풍선(대화·표현) 또는 엽서 메모(어휘·문법), 쪽번호 = 우표 도장, 진행 표시 = 비행기가 나는 항공 노선(`#orbit`의 비행기).
- 표지: 단원 영어 제목을 큰 글자로(교과서 표지처럼 두 줄까지), 소재에 맞는 간단한 장면 SVG(`.scene`, 예: 미술관 액자·직업 건물·지갑과 동전). 장면은 단원 전용이라 `figures/`에 둔다.

## 색 변수 (`config/slide-v2/g1s2-english/base.css` `:root`)
| 변수 | 값 | 용도 |
|---|---|---|
| `--bg` | `#EEF5FF` | 연한 하늘 바탕 |
| `--bg-3` | `#1F3F73` | 표 머리·테두리(남색) |
| `--ink` / `--ink-dim` | `#14233F` / `#4A5F80` | 본문 / 보조 글자 |
| `--brass` | `#C23B22` | 강조(우표 붉은색). 흰 바탕 대비 충분 |
| `--purple` | `#2D5A8C` | 소제목, 표 첫 열(앱 영어 과목색) |
| `--line` | `#4F86C6` | 카드 테두리 |
| `--cyan` / `--star` | `#39B8E8` / `#FFC83D` | 장식 포인트 |
| `--warn` / `--warn-line` | `#B93A12` / `#E8552D` | 흔한 오류·주의 카드 |
| `--stage-bg` | `#0F2547` | 무대 바깥 여백 |
- 글꼴은 과학과 같음: 제목 Jua, 본문 Gowun Dodum(영문도 이 글꼴로 읽힌다). 영어 예문은 `<b>`로 강조하고 한국어 뜻은 보조색.

## 영어 슬라이드에서 쓰는 틀 (장 구성 예시, 단원마다 10~12장)
1. 표지(제목·소재·의사소통 기능·언어 형식 알약) 2. 단원 한눈에 3~4. 핵심 어휘(표: 영어·품사·뜻·예문, 단어 관계) 5. 핵심 표현(대화 말풍선 A/B) 6~7. 언어 형식(형태·의미·쓰임 표 + **자주 하는 오류** 경고 카드) 8~9. 본문 흐름(문단별 요약 타임라인) 10. 헷갈리기 쉬운 것(비교표) 11. 시험 포인트(어휘·어법·대화·독해) 12. 마무리 체크.
- 문법 장에는 반드시 '틀린 문장 → 고친 문장'을 보여 주는 `.warn` 카드.
- 대화는 말풍선 두 개(A 왼쪽, B 오른쪽)로, 교과서 대화문 전체를 옮기지 않고 핵심 표현 문장만.

## 가독성·태블릿
- 본문 최소 24px(무대 기준), 표·그림 안 글자도 24px 이상(가로 1280 태블릿에서 실효 16px 이상 유지). 영어 예문은 한 줄에 너무 길게 쓰지 않는다.
- 모바일·태블릿 세로 카드 배치는 `base.css`가 처리한다(조각에 별도 `<style>` 금지).
