# 과학 슬라이드 스타일 (우주 탐험 / 로켓)

과학 요약 슬라이드(`library/g1s2-science/u*/slides.html`)에 쓰는 과목 전용 디자인. 공통 스타일(`slide-style.md`, 칠판+황동)을 이 과목에서는 쓰지 않는다. 구조(1920x1080 무대, 키보드·버튼 이동, 820px 이하 세로 카드 전환, 편집 모드)는 공통과 같다.

## 메타포
- 교과서 표지: 핑크 배경, 흰 로켓 안에서 우주복 입은 고양이·다람쥐가 지구를 안고 있음, 달 표면·위성·토성·UFO·별.
- 슬라이드 = 우주선 창문 안의 장면. 카드는 둥근 창문, 쪽번호는 행성, 진행 표시는 로켓의 궤도 비행.

## 색 변수 (`:root`)
| 변수 | 값 | 용도 |
|---|---|---|
| `--bg` | `#FFF1F8` (슬라이드 바탕은 `#FFE6F3`→`#FFF4EC` 그라데이션) | 밝은 핑크~크림 바탕 |
| `--bg-2` | `#FFFFFF` | 카드·도식 상자 |
| `--bg-3` | `#3B2A7A` | 표 머리·창틀 테두리(딥퍼플) |
| `--ink` | `#261A52` | 본문 글자 (흰 바탕 대비 약 15:1) |
| `--ink-dim` | `#5A4F85` | 보조 글자 |
| `--brass` | `#C2186B` | 강조(마젠타), 기존 변수명 유지. 흰 바탕 대비 약 6:1 |
| `--purple` | `#5B2AA6` | 소제목 h3, 표 첫 열 |
| `--line` | `#7A4FD0` | 일반 카드 테두리 |
| `--cyan` / `--star` | `#39C6E8` / `#FFC83D` | 장식 포인트(리벳, 별, 행성 고리) |
| `--warn` / `--warn-line` | `#B93A12` / `#E8552D` | 오해·주의 카드 (바탕 `#FFF3EC`) |
| `--stage-bg` | `#1B1245` | 무대 바깥 여백(우주 남색) |

인라인 SVG 색 치환 규칙: 황동 `#c9a24b`→`#C2186B`, 크림 `#f3ead3`→`#261A52`, 노랑 `#e8c76a`→`#FFC83D`, 코랄 `#e08a6a`→`#D9461F`. 도식 상자는 흰 바탕이라 선·글자는 어두운 색으로 둔다.

## 글꼴 (Google Fonts)
- 제목·소제목·표 머리·쪽번호: Jua (둥글고 귀여운 한글)
- 본문: Gowun Dodum (굵기 400 하나라 `b`는 색 강조 + 합성 굵기)
- 대체: 'Malgun Gothic', sans-serif

## 장식 규칙
- 장식은 모두 `z-index:-1` 배경 레이어(`.slide::before`, `isolation:isolate`)나 카드 테두리 위 소품이라 본문을 가리지 않는다.
- 본문 슬라이드: 점선 창틀, 오른쪽 위 토성+궤도, 가장자리 별(여백에만), 아래 달 표면 곡선(하단 패딩 영역 안).
- 카드: 굵은 테두리 + 둥근 모서리(30px) + 아래 그림자. `.hl`은 마젠타 테두리 + 안쪽 분홍 링 + 테두리 위 시안 리벳. `.warn`은 코랄.
- 목록 불릿은 별, h2 앞은 노란 행성 점, 순서 번호(`.no`)는 마젠타 원, `.kicker`는 마젠타 알약.
- 표: 딥퍼플 머리 + 흰/연핑크 줄무늬 + 둥근 바깥 테두리.
- 쪽번호 `.pg`: 보라 행성 + 노란 고리(오른쪽 아래 달 표면 위).
- 표지: 위(딥퍼플)에서 아래(핑크)로 번지는 하늘, 왼쪽에 제목(흰색, 강조어는 노랑), 오른쪽에 로켓 발사 장면 SVG(`.scene`: 고양이 창문 로켓, 토성, UFO, 지구, 연기, 달 표면). 모바일에서는 제목 아래로 축소 배치.
- 진행 표시(`.deck-controls`): 남색 알약 안에 호 모양 궤도(지구→달). `show()`가 로켓 위치·진행선을 갱신한다(`#orbitPath`, `#orbitDone`, `#rocketMark`).
- 모바일(820px 이하): 슬라이드마다 둥근 카드, 아래에 달 표면 띠, 쪽번호는 작은 행성.

## 가독성 기준
- 본문 최소 24px(무대 기준) 유지. 어두운 글자+밝은 바탕, 표지만 어두운 하늘 위 흰/노랑 글자.
- 새 과학 슬라이드는 이 CSS 블록(`<style>` 전체), 표지 `.scene` SVG, 컨트롤(`#orbit`)을 기존 단원 파일에서 그대로 복사해 쓴다.
