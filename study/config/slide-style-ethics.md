# 도덕 슬라이드 스타일 (마음의 산책)

도덕 교과 정리 슬라이드(`library/g1s2-ethics/u*/slides.html`)에 쓰는 과목 전용 디자인. 과목 표지(`cover.jpg`)의 메타포를 따른다. 공통 칠판 스타일(`slide-style.md`) 대신 도덕 과목에만 적용한다. 구조·컨트롤러·마크업 규약은 `library/g1s2-social/u1/slides.html`과 같고 색·글꼴·장식·표지·진행 표시만 다르다.

## 메타포
- 표지의 "파란 하늘, 큰 뭉게구름, 초록 풀밭 언덕에 앉은 소녀와 강아지" -> **마음의 산책** (구름 아래 풀밭에서 천천히 나를 돌아보는 시간).
- 슬라이드 한 장 = 산책길에서 쉬어 가는 자리 한 칸. 단원 전체 = 산책 한 번. 가치 판단을 몰아가지 않고 차분히 개념을 정리하는 분위기.
- 교과서 그림은 쓰지 않는다. 표지 사진을 넣거나 베끼지 않고 SVG를 새로 그린다. 학교·교사 이름은 넣지 않는다.

## 색상 (`:root` 변수)
| 변수 | 값 | 용도 |
|---|---|---|
| `--sky` / `--sky-l` | `#8fcdf5` / `#e6f4fd` | 하늘 (슬라이드 위쪽 그라데이션, 표지) |
| `--cloud` | `#ffffff` | 구름 (장식, 표지) |
| `--grass` / `--grass-d` | `#5db75a` / `#2f7d46` | 풀밭, 진행 표시 (`--grass-d` 위 흰 글자 AA) |
| `--bg` / `--bg-2` | `#fbfdf9` / `#ffffff` | 슬라이드 바탕 / 카드 |
| `--ink` / `--ink-dim` | `#1f2a3d` / `#4a5872` | 본문 / 보조 글자 (바탕 대비 AA 이상) |
| `--navy` | `#1c3a5e` | 제목, 표 머리 (표지의 짙은 손글씨 제목 색) |
| `--em` / `--warn` | `#b3450b` | `<b>` 강조, 오해·주의 카드 제목 |
| `--line` | `#bfdcc9` | 카드·표 테두리 |
| `--flower` | `#f2c230` | 풀밭의 작은 노란 꽃 (장식 전용, 글자에 쓰지 않음) |
| `--pt` | 단원별 | 포인트색: 키커 알약, 잎 불릿, 번호 원, `.tag`, `.lb`, `.card.hl` 왼쪽 띠 |

단원별 `--pt` (흰 글자 대비 AA 이상, 10색 순환): u1 `#1f6fb5` 파랑, u2 `#2f7d46` 초록, u3 `#b3450b` 주황, u4 `#8a4fb0` 보라, u5 `#a8326e` 자주, u6 `#0f766e` 청록, u7 `#8f5a00` 갈색, u8 `#4b53b8` 남보라, u9 `#b0392f` 빨강, u10 `#3f7d1f` 연두녹.

## 글꼴 (Google Fonts)
- 제목·표 머리·번호: **Gaegu** 700 (표지 '도덕'의 둥근 손글씨 느낌)
- 본문: **Noto Sans KR** 400/500/700/900 (가독성 우선)
- 대체: 'Malgun Gothic', sans-serif

## 장식 규칙
- 장식은 가장자리에만 두고 본문 뒤(`z-index:0`)에 둔다. 본문은 위(`z-index:1`).
- 본문 슬라이드: 위쪽 하늘 그라데이션, 오른쪽 위 작은 뭉게구름 두 덩이(`.slide::before`, 옅게, 제목 줄 높이 안), 아래쪽 풀밭 언덕 + 노란 꽃 점 띠(`.slide::after`, 높이 74px).
- 불릿: 작은 잎 모양(`ul.l li::before`, `border-radius: 0 100% 0 100%`).
- 카드: 흰 바탕, 둥근 모서리 22px(구름처럼), 연초록 테두리. `.hl`은 왼쪽에 `--pt` 띠, `.warn`은 주황 띠 + 연한 주황 바탕.
- 표: 머리는 남색 바탕 + 흰 글자, 본문 행은 흰색/연초록 줄무늬.
- 번호 원(`.step .no`): `--pt` 원 + 흰 테두리.
- 꼬리표는 굵은 글씨 대신 `<span class="lb">…</span>` 색 알약.

## 표지
- 하늘 그라데이션 -> 큰 뭉게구름(제목 뒤쪽 오른편) -> 먼 덤불 -> 초록 언덕 두 겹 -> 풀밭에 앉은 소녀와 강아지(오른쪽 아래, 새로 그린 단순한 도형). 제목은 남색 Gaegu, 강조어 `<span>`은 남색 알약. 왼쪽 아래에 단원 번호 표지판(`.sign`). 마크업은 `.scene`(SVG) + `.copy`(텍스트) + `.sign`.
- 모바일: 위에 글, 아래에 풀밭 풍경(구름·하늘 장식은 숨김).

## 진행 표시 (`#controls`)
- 풀밭 길(연한 초록 막대) 위를 걷는 강아지 + 슬라이드마다 작은 구름 점, 끝에 나무. 지나온 길은 진한 초록. `#count` 텍스트 변화를 따라가는 별도 스크립트(기존 컨트롤러 코드는 건드리지 않음).

## 인라인 SVG 규칙
- 칠판 색을 쓰지 않는다. 상자 흰 바탕 + 파란 선(`#2b6cb0`), 글자 남색 `#1c3a5e`, 강조 글자 `#a3430a`, 색 상자 위 글자는 흰색(상자는 `#1f6fb5` / `#2f7d46` / `#a35a10`), 보조 글자 `#44557a`.
- 글자 크기는 SVG 좌표 기준 22 이상. 모바일에서 줄어들어도 읽히게 가로 폭을 1000 안팎으로 설계한다.
- 교과서 그림을 옮기지 않고 개념 관계(원, 화살표, 상자)만 새로 그린다.

## 레이아웃 규칙 (공통 스타일과 동일)
- 1920x1080 고정 무대를 뷰포트에 맞춰 축소. 본문 최소 글자 크기 24px(무대 기준).
- 폭 820px 이하 세로 화면은 세로 스크롤 카드로 전환 (표지는 위에 글, 아래에 풀밭 풍경).
- 편집 모드(E), 키보드·버튼·터치 이동 동작은 그대로.
