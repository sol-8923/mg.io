# 사회 슬라이드 스타일 (하이킹 지도)

사회 요약 정리 슬라이드(`library/g1s2-social/u*/slides.html`)에 쓰는 과목 전용 디자인. 과목 표지(`cover.jpg`)의 메타포를 따른다. 공통 칠판 스타일(`slide-style.md`) 대신 사회 과목에만 적용한다.

## 메타포
- 표지의 "산길을 걸어 올라가며 세상을 탐험하는 두 하이커" -> **하이킹 / 지도 탐험**.
- 슬라이드 한 장 = 길 위의 이정표 한 칸. 단원 전체 = 하이킹 한 번.

## 색상 (`:root` 변수)
| 변수 | 값 | 용도 |
|---|---|---|
| `--sky` / `--sky-l` | `#8ec9f0` / `#e3f3fc` | 하늘 (슬라이드 위쪽 그라데이션, 표지) |
| `--hill` / `--hill-d` | `#4fae4e` / `#2f7d46` | 초록 언덕, 진행 표시 |
| `--path` | `#efdcb2` | 흙길 베이지 |
| `--bg` / `--bg-2` | `#fbfdf8` / `#ffffff` | 슬라이드 바탕 / 카드 |
| `--ink` / `--ink-dim` | `#1e2a44` / `#46567a` | 본문 / 보조 글자 (바탕 대비 AA 이상) |
| `--navy` | `#1b2f63` | 제목, 표 머리 (표지의 남색 제목) |
| `--em` / `--warn` | `#b3450b` | `<b>` 강조, 오해·주의 카드 제목 |
| `--line` | `#bcd6c2` | 카드·표 테두리 |
| `--pt` | 단원별 | 포인트색: 키커 알약, 핀 불릿, 이정표 번호, `.tag`, `.card.hl` 왼쪽 띠 |

단원별 `--pt` (흰 글자 대비 AA 이상, 6색 순환): u1 `#c2570c` 주황, u2 `#6b46a8` 보라, u3 `#1f7a45` 초록, u4 `#1f5fa8` 파랑, u5 `#a8326e` 자주, u6 `#0f766e` 청록, u7~u12는 같은 순서로 반복.

## 글꼴 (Google Fonts)
- 제목·표 머리·이정표: **Jua** (둥글고 두꺼운 교과서 표지 느낌)
- 본문: **Noto Sans KR** 400/500/700/900 (가독성 우선)
- 대체: 'Malgun Gothic', sans-serif

## 장식 규칙
- 본문 슬라이드: 위쪽 하늘 그라데이션, 오른쪽 위 나침반 + 등고선(`.slide::before`, 옅게), 아래쪽 초록 언덕 + 점선 흙길 띠(`.slide::after`, 높이 74px). 장식은 본문 뒤(`z-index:0`)에 두고 본문은 위(`z-index:1`)에 둔다.
- 불릿: 지도 핀 모양(`ul.l li::before/::after`).
- 카드: 흰 바탕, 둥근 모서리 18px, 초록 테두리. `.hl`은 왼쪽에 `--pt` 띠, `.warn`은 주황 띠 + 연한 주황 바탕.
- 표: 머리는 남색 바탕 + 흰 글자, 본문 행은 흰색/연초록 줄무늬.
- 이정표 번호(`.step .no`): `--pt` 원 + 흰 테두리.
- 인라인 SVG: 칠판 색을 쓰지 않는다. 상자 흰 바탕 + 파란 선(`#2b6cb0`), 글자 남색 `#1b2f63`, 강조 글자 `#a3430a`, 색 상자 위 글자는 흰색(상자는 `#a35a10` / `#1f7a45`).
- 표지: 하늘 -> 먼 언덕(풍차·농가·스카이라인) -> 초록 언덕(소·양) -> 위로 올라가는 흙길 위 두 하이커. 제목은 남색 Jua, 강조어 `<span>`은 남색 알약. 왼쪽 아래에 단원 번호 이정표 표지판(`.sign`). 표지 마크업은 `.scene`(SVG) + `.copy`(텍스트) + `.sign`.
- 진행 표시(`#controls`): 흙길 막대 위를 걷는 하이커 + 슬라이드마다 이정표 말뚝, 끝에 깃발. 지나온 길은 초록. `#count` 텍스트 변화를 따라가는 별도 스크립트(기존 컨트롤러 코드는 건드리지 않음).

## 레이아웃 규칙 (공통 스타일과 동일)
- 1920x1080 고정 무대를 뷰포트에 맞춰 축소. 본문 최소 글자 크기 24px(무대 기준).
- 폭 820px 이하 세로 화면은 세로 스크롤 카드로 전환 (표지는 위에 글, 아래에 언덕 풍경).
- 편집 모드(E), 키보드·버튼·터치 이동 동작은 그대로.
