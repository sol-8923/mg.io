# 오답풀이 작성 (study-explain)

앱의 **상세 오답풀이**는 틀린 문제를 한 문제당 한 페이지씩 보여 준다. 화면 구성:
`내 답 / 정답` → `🤔 왜 틀렸을까?`(고른 오답의 해설) → `🔍 정답 풀이` → `🧩 보기별 분석` → `💡 기억할 점` + 옆(태블릿)·탭(폰)에 `📎 참고 자료`.
실시간 생성은 없다. 이 스킬이 미리 써 둔 내용이 그대로 나온다. **틀린 내용이 있으면 아이가 잘못 배우므로**, 모든 내용은 원문에 근거하고 `review-explanation`·`review-content` 검수를 거친다.

## 입력
`drafts/<책id>/<단원id>/questions.json`, `notes.md`, `materials/…`(원문)

## 문항별로 채울 항목
| 항목 | 대상 | 작성 규칙 |
|------|------|-----------|
| `detail` | 전부 | **상세 정답 풀이.** 개념 정리 → 이 문제에 적용 → 결론. 4~8줄, `·` 목록·줄바꿈 활용. 그래프·표 문항은 "자료를 읽는 순서"를 보여 준다 |
| `choiceExplanations` | 선택형 | 보기마다 1~2문장. 오답 보기는 **"왜 이걸 골랐을지(오해)" + "실제로는 어떤지"**. 정답 보기는 "정답."으로 시작. 합답형은 어떤 ㄱㄴㄷ이 맞고 틀렸는지 |
| `commonMistakes` | 단답형 | 실제로 자주 쓰는 오답 1~3개 + 이유. 정답과 겹치면 안 됨 |
| `wrongExplanation` | OX | 반대로 답한 학생의 흔한 오해 |
| `rubric[].tip` | 서술형 | 그 기준이 빠졌을 때 무엇을 어떻게 보완하는지 |
| `tip` | 전부 | 다음에 안 틀리는 요령·암기법 한 줄 (원문과 어긋나지 않게) |
| `refs` | 전부 | **참고 자료 1~3개** (아래) |

## 참고 자료 (`refs`)
오답풀이를 읽다가 **바로 옆에서 확인할 수 있는** 그림·표·개념 카드. 문항의 그림을 반복하기보다, 이해를 돕는 자료를 붙인다.
```json
"refs": [
  { "kind": "svg",   "title": "가열 곡선 구간별 상태", "svg": "<svg …>…</svg>", "caption": "수평 구간 = 상태 변화 중" },
  { "kind": "table", "title": "상태 변화와 열에너지", "head": ["상태 변화","방향","열에너지"], "rows": [["융해","고체 → 액체","흡수"]] },
  { "kind": "text",  "title": "자주 하는 오해", "text": "고체 입자도 제자리에서 진동해요…" }
]
```
- `svg`: 개념 도식, 그래프에 구간·라벨을 덧붙인 버전, 입자 모형, 비교 그림. **원문 그림을 베끼지 말고 새로 그린다.** 진한 색, 정확한 수치·라벨, 스크립트·외부 링크 금지.
- `table`: 비교표·정리표. head와 각 row의 칸 수가 같아야 한다.
- `text`: 핵심 개념 카드, 자주 하는 오해, 생활 속 예.
- 같은 단원 안에서는 같은 참고 자료를 여러 문항이 공유해도 된다(일관성).

## 공통 규칙
- 말투: 중학생에게 말하듯 "~예요/~해요".
- **보기 번호 금지**: `fixedOrder`가 없는 선택형은 보기 순서가 섞이므로 ①~⑤로 가리키지 말고 보기 내용으로 가리킨다(빌드가 거부).
- 원문 근거: 원문에 없는 사실, 교과서와 다른 용어 금지. 확실하지 않으면 쓰지 말고 보고한다.
- 풀이가 정답·채점 기준과 모순되면 안 된다(정답이 틀렸다고 판단되면 고치지 말고 `quiz` 반려 사유로 보고).

## 점검
`python engine/build_library.py --check-unit drafts/<책id>/<단원id>` → `✖` 0개, `⚠`의 "refs 없음 / tip 없음 / commonMistakes 없음"도 해소.

- **과목별 기준(사용자 지시)**: 해당 과목의 `docs/subjects/<과목>.md`를 먼저 읽고 따른다. **가장 먼저 '0. 기출 유형'**(학교 기출에서 나온 시험 구성·난이도 배분·출제 경향·반영 규칙, 사용자 지시 2026-11-15 최우선)을 읽고, 다른 항목·`docs/내신-적합성-검토와-개정안.md`의 권장값과 어긋나면 기출 유형이 이긴다. 그다음 '출제 형식', '지문·자료 규칙', '자주 나온 반려 사유', '다음 단원에서 개선할 것'을 본다.
