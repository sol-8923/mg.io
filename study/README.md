# study — 민겸이 공부 공간

교과서·자습서 내용을 넣으면 **매번 새로 조합되는 내신형 시험**, **한 문제씩 넘기는 상세 오답풀이**, **학년·학기·과목별 오답노트**를 제공하는 웹앱과, 그 문제 은행을 만드는 Claude Code 작업 환경.

- 사이트: https://sol-8923.github.io/mg.io/study/ (갤럭시 탭·폰 화면에 맞춤)

## 사용법
1. 자료 넣기: `materials\1학년\2학기\과학\` 에 교과서·자습서 사진, PDF, 텍스트. **단원별로 나눌 필요 없음** — Claude가 차례·단원명을 보고 구분한다. 학교 기출은 같은 폴더의 `기출\`에.
   - 폴더는 1~3학년 × 1~2학기 × 국어·영어·수학·과학·사회·역사·도덕·기술·가정·정보로 미리 만들어 두었다.
2. `E:\dev\mg.io`에서 Claude Code 실행 → `/study 1학년 2학기 과학` (특정 단원만: `/study 1학년 2학기 과학 2단원`)
3. 단원마다 `drafts\`(git 제외)에서 문제 은행을 만들고 4중 검수(내용 검수 Opus, 나머지 Sonnet)를 받는다. **만장일치로 통과한 단원만** `library\`로 옮겨 push된다.
   - **기출이 있으면** 두 가지로 쓴다: ① 출제 패턴(발문 말투·자료 형태·오답 함정·서술형 조건)을 분석해 `exam-patterns.md`로 만들고 새 문제를 그 스타일로 만든다. ② 기출 문항 하나하나를 문제 은행 문항(`origin: "past-exam"`)으로 바꿔 넣는다. 기출 변환 문항도 4중 검수를 똑같이 받고, 내용 검수가 기출 원본과 대조한다. 기출을 나중에 추가하고 같은 명령을 다시 실행하면 새 기출만 반영한다.
4. 사이트에서 "새로운 시험 보기" → "시험 범위를 골라주세요"에서 단원을 고르면 그 단원 문제만 나온다. 같은 명령을 다시 실행하면 문제 은행이 보강된다.

## 주의
저장소와 사이트는 공개다. 결과물은 교과서 문장·그림을 그대로 옮기지 않고 요약·재구성하며, 그림은 새로 그린 SVG만 쓴다. 교과서 사진 원본(`materials/`)은 git에 올리지 않는다.
샘플 책 8권(수학·국어·사회·도덕·과학·역사·영어)은 2026-11-15에 `library/`에서 빼서 내 PC의 `samples/`에만 보관한다(GitHub에는 없음, `.gitignore`). 실제 자료로 만든 책만 `library/`에 두고 올린다. 샘플을 만들며 개선한 에이전트·스킬·제작 기준(`.claude/`, `docs/내신-적합성-검토와-개정안.md`, `docs/도덕-출제-기준.md`)은 그대로 유지한다. `meta.json`의 `sample: true`는 샘플 크기·임시 축약 검수를 허용하는 표시이므로 실제 책에는 쓰지 않는다.

## 기록 저장
시험 기록·오답노트·대시보드 통계·펜 필기는 각 기기(브라우저)에 저장된다. 지워지기 쉬우므로 공부방 화면 맨 아래의 **백업** 카드를 쓴다.
- ⬇ 내보내기: 기록+필기를 파일로 저장하고, 인터넷이 되면 Firebase(`backups` 컬렉션)에도 함께 올린다.
- 클라우드 백업은 로그인이 없는 대신 **백업 코드**(20자 무작위, 카드 맨 아래에 표시·내보낸 파일 안에도 기록)를 아는 기기만 읽을 수 있다. 코드는 따로 적어 두자.
- ⬆ 가져오기(파일) / ☁ 클라우드에서 복원(코드): 기존 기록을 지우지 않고 더 최신인 것·없는 것만 합친다. 필기는 같은 획이 겹치지 않게 합친다.
- 규칙(`firestore.rules`의 `backups`)을 바꿨다면 `firebase deploy --only firestore:rules`로 올려야 클라우드 백업이 동작한다.

## 우리 집 일정을 모든 기기에서 공유하기
일정(루틴·달력·해야 할 일)은 알림과 같은 Firebase 프로젝트(`mg-study`)의 `plan/routine`, `plan/events`, `plan/todos` 문서에 저장되고, 폰·탭이 같은 일정을 본다. **보안 규칙은 이미 적용돼 있다**(2026-11-15). 규칙 전문은 `firestore.rules`에 있다.
- 알림(`notices`)과 일정(`plan`)만 읽고 쓸 수 있고 나머지 경로는 전부 막혀 있다. 일정은 3개 문서만, 100KB 미만만 쓸 수 있고 삭제는 막혀 있다.
- 규칙을 고쳐서 다시 올릴 때: `firebase login` 후 `firebase.json`(`{"firestore":{"rules":"firestore.rules"}}`)을 둔 폴더에서 `firebase deploy --only firestore:rules --project mg-study`. 올리기 전에 콘솔의 현재 규칙과 비교해 `notices`가 지워지지 않게 한다.
- 인터넷이 불안정하면 일정 페이지 위쪽에 안내가 뜨고 이 기기에 저장된 내용을 보여 준다.

도덕 과목의 출제·검수 기준은 `docs/도덕-출제-기준.md`에 있다.

## 교실 문과 교과서 표지
- 시험·오답노트는 먼저 **학년·학기 교실 문**(1학년 1학기 ~ 3학년 2학기)을 고른 뒤 그 학기 책장이 나온다. 교과서가 없는 학기는 닫힌 문('준비 중')으로 보인다.
- 교과서 표지 이미지를 `materials/<N>학년/<M>학기/<과목>/표지.jpg`(또는 png·webp, 파일명 `표지` 또는 `cover`)로 넣고 `python engine/build_library.py`를 실행하면 책장의 책이 그 표지 그림으로 나온다. 이미지가 없으면 기존 책 디자인을 쓴다.
- 표지 이미지는 `library/<책>/cover.*`로 복사되어 커밋·push되고 배포 사이트에도 보인다(가족용이라 주소를 공유하지 않는다는 전제로 사용자가 정함). 이미지는 800KB 이하를 권장한다.

## 가족 채팅
- 홈의 '가족 채팅'(`#/chat`)에서 엄마·아빠·민겸이 글과 사진을 실시간으로 주고받는다. Firebase 라이브러리(`onSnapshot`)로 새 글이 바로 뜬다.
- 처음 한 번 '누구세요?'에서 아빠/엄마/민겸을 고르면 그 기기에 기억되고, 헤더의 '바꾸기'로 바꾼다. 안 읽은 글이 있으면 홈 카드에 NEW가 뜬다.
- 사진은 기기에서 긴 변 1000px JPEG로 줄여(70만 자 이하) 문서에 글자 데이터로 함께 저장한다(Firebase 저장소 불필요, 무료). 최근 40개만 불러온다.
- 데이터: Firestore `chat/{자동id}` = `{who, text, img?, at}`. 규칙은 `firestore.rules`의 `chat` 항목(글 500자, 사진 70만 자 제한, 수정 불가, 누구나 읽기·쓰기·삭제). 로그인이 없으므로 주소를 공유하지 않는 전제다.
- 규칙은 `firebase deploy --only firestore:rules --project mg-study`로 배포해야 동작한다.
- **한 사람은 한 기기에서만**: 고른 사람은 Firestore `chatwho/{dad|mom|min}` = `{device, at}`에 기기 번호로 기록된다. 다른 기기에서 같은 사람을 고르면 '이 기기로 옮길까요?'를 묻고, 옮기면 원래 기기는 선택이 풀려 다시 고르게 된다. '바꾸기'를 누르면 선택이 풀려 다른 기기가 쓸 수 있다. 로그인이 없는 가족용 잠금이라 보안 기능은 아니다.
- **읽음 표시**: 선택한 사람이 채팅 화면을 보고 있으면 Firestore `chatread/{dad|mom|min}` = `{at}`에 '여기까지 읽음' 시각이 기록되고, 내가 보낸 글 아래에 '아빠 읽음' / '모두 읽음'이 뜬다.
- **새 메시지 알림**: 채팅 화면의 '알림 켜기'로 브라우저 알림을 허용하면, 그 기기에서 앱(탭)이 열려 있는 동안 새 메시지가 오면 알림이 뜬다(`sw.js`). 앱을 완전히 닫았을 때의 푸시 알림은 서버(Cloud Functions, 유료 Blaze 요금제)가 필요해 아직 없다. iPhone은 홈 화면에 추가한 앱에서만 알림이 된다.
- **푸시 알림(앱을 닫아도)**: `functions/index.js`의 `notifyChat`(Cloud Function, 서울 리전)이 새 채팅 문서가 생기면 보낸 사람을 뺀 다른 가족 기기(`chattokens/{기기번호}` = `{who, token, at}`)로 FCM 알림을 보낸다. 기기는 '알림 켜기'를 누를 때 번호가 등록된다. 함수 배포는 Firebase **Blaze(종량제) 요금제**가 필요하다: `firebase deploy --only functions --project mg-study` (study 폴더에서).
- **채팅 자동 청소**(`cleanupChat`, 매일 새벽 4시): ① 90일이 지난 글을 지우고, ② 추정 저장 용량이 Blaze 무료 한도(1GiB)의 85%에 이르면 가장 오래된 글부터 지워 40%까지 줄인다. 용량은 글 크기(`sz`, 알림 함수가 기록)와 글당 색인 여유분으로 추정한 값이라 실제 청구 용량과 조금 다를 수 있다. 상수는 `functions/index.js` 위쪽(`FREE_LIMIT`, `HIGH`, `LOW`, `KEEP_DAYS`)에서 바꾼다.
- **채팅 비밀번호**: 채팅에서 아빠·엄마를 고를 때 그 기기에서 **처음 한 번** 비밀번호를 묻는다(민겸이는 없음). 비밀번호는 '아빠가 알림'·'엄마가 알림'과 같은 값이다. 비밀번호 입력창의 '비밀번호 바꾸기'에서 지금 비밀번호를 입력하면 새 값으로 바꿀 수 있고, 바꾸면 알림과 채팅에 모두 적용된다. 기본값은 `Notice.who[].pw`(코드), 바꾼 값은 Firestore `secrets/{dad|mom}.pw`에 평문으로 저장된다(요청에 따라 암호화 없음, 누구나 읽을 수 있으므로 중요한 비밀번호로 쓰지 말 것).
