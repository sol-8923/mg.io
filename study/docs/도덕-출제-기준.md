# 도덕 과목 출제·검수 기준 (2026-11-15)

도덕은 암기 과목이 아니라 **개념을 구분하고 사례에 적용하는 과목**이다. 다른 과목의 공통 규칙(R1~R9, `내신-적합성-검토와-개정안.md`)을 따르되, 아래를 더한다. 이 기준은 `exam-designer`·`study-quiz`·`review-*` 에이전트의 과목별 형식 표에도 반영되어 있다.

## 1. 출제 형식
| 구분 | 형태 |
|------|------|
| 선택형(5점) | ① 개념 설명 고르기(정의·구분) ② 사례 적용(상황 → 해당 덕목·개념) ③ 〈보기〉 합답(ㄱ~ㄹ) ④ 비교 구분(자존감/자존심, 용서/용납 등) ⑤ 입장·관점 파악(철학자·사상가) |
| 단답형(4점) | 핵심 용어 쓰기(정답이 한두 낱말인 것만). 정답이 여러 가지로 해석되는 서술적 용어는 피한다 |
| 서술형(8점) | **사례 제시 → 개념 적용 → 조건 낱말** 구조. 모범 답안이 한 가지로 수렴하도록 조건 낱말을 둔다 |

한 단원에서 위 형태를 3종 이상 섞는다.

## 2. 도덕 특유의 규칙
1. **가치 판단의 정답은 하나로 수렴해야 한다.** "옳다고 생각하는가"처럼 의견을 묻는 문항은 출제하지 않는다. 교과서가 정한 개념·기준(정의, 덕목, 사상가의 입장)을 묻는다.
2. **선택지 단서 금지**: 정답만 도덕적으로 "착한 말"이 되지 않게 한다. 오답도 그럴듯한 도덕적 표현(예: "남을 배려하지만 자신은 소홀히 한다")으로 쓰고, 어디가 틀렸는지 해설에 밝힌다.
3. **극단 표현 의존 금지**: "항상, 절대, 모두"가 들어간 보기를 오답 신호로 쓰지 않는다. 정답 보기에도 같은 정도의 단정이 들어갈 수 있게 한다.
4. **사례 문항은 현실적인 중학생 상황**(학교, 가족, 친구, 온라인)으로 쓰고, 특정 개인·실존 인물의 사건은 쓰지 않는다.
5. **서술형 채점**: ①개념 설명 ②사례 적용 ③조건 낱말 사용으로 배점을 나누고, 조건 낱말은 채점 기준에 `('낱말' 사용)`으로 적는다. 의견·가치 판단이 정답에 들어가는 서술형은 "근거를 든 판단"만 점수를 준다.
6. **개념 누출 금지**: 단답형 정답 용어(예: 중용, 네티켓)는 같은 단원의 다른 슬롯 발문·지문·보기에 쓰지 않는다. 자동 점검(`check_rev`)이 확인한다.
7. **용어는 교과서 우선**: 자료 출처가 위키백과 등 일반 문헌이면 학교 교과서와 용어·분류가 다를 수 있으므로 `notes.md`에 "교과서 용어와 다를 수 있음"을 적고, 정식 교과서 자료가 들어오면 그 용어로 교체한다.
8. **민감한 주제**(학교 폭력, 사이버 폭력, 죽음 등)는 사실·개념·예방 중심으로 쓰고 폭력 장면을 구체적으로 묘사하지 않는다.

## 3. 검수 체크리스트(검수 에이전트 공통)
- 정답이 교과서 개념 기준으로 유일한가(가치 판단 문항이 아닌가)
- 오답이 "명백히 나쁜 행동"이라서 소거만으로 풀리지 않는가
- 사례가 단원의 핵심 개념과 직접 연결되는가
- 서술형 조건 낱말이 채점 기준에 반영됐는가
- 정답 용어가 다른 문항에 노출되지 않았는가

## 4. 현재 샘플 상태
- `g1s1-ethics`(1학기 자신과의 관계·도덕적 삶), `g1s2-ethics`(2학기 타인과의 관계): 위키백과(CC BY-SA 4.0) 문서 요약을 원문으로 한 자체 제작 샘플이며, 실제 교과서 단원 구성과 다를 수 있다.
- 검수는 임시 축약 검수(자체 점검 + 자동 점검)이고 4중 검수는 거치지 않았다.
- 한계: 도덕 교과서의 실제 사례·활동·용어와 단원 구성을 반영하지 못했다. 교과서·자습서 자료를 `materials/1학년/<학기>/도덕/`에 넣으면 그 자료를 우선해 다시 만든다.
