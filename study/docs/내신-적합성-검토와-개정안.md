# 샘플 6권의 중학 내신 적합성 검토와 개정안

작성일: 2026-11-15 · 대상: `library/` 샘플 6권(1-1 수학·국어·사회, 1-2 과학·역사·영어, 각 1단원·12슬롯·24문항)

## 0. 범위와 한계 (먼저 읽을 것)
- 이 검토는 **일반적인 중학교 지필평가 관행에 대한 판단**과 **샘플의 실제 통계**를 근거로 한다. 특정 학교의 기출, 교사의 검수, 학생 응시 결과(정답률·변별도)는 없다.
- 샘플은 교과서가 아니라 공개 자료(위키백과 등)를 원문으로 만들었고, 수학·역사·국어·사회·영어는 **임시 축약 검수**(자체 점검 1회)만 거쳤다. 과학만 4중 검수를 만장일치로 통과했다.
- 따라서 "내신에 적합하다/않다"는 결론은 **개정안을 세우기 위한 진단**이며 합격 판정이 아니다.

## 3. 개정안 (R1~R9)
| 번호 | 내용 | 반영 대상 |
|------|------|-----------|
| R1 | **현실적인 규모·배점**: 선택형 3~5점, 단답 3~4점, 서술형 4~8점. 단원 정식 설계는 15~20슬롯, 서술형은 3~5문항(비중 20~40%). 샘플 크기(12슬롯)는 예외로 표시. 빌드가 배점 범위를 경고 | `exam-designer`, `study-quiz`, `review-overall`, `build_library.py` |
| R2 | **사실 배분표**: 설계 단계에서 슬롯마다 '정답 근거 사실'을 적고, 다른 슬롯의 발문·지문·보기에 그 사실이 **참으로 단언**되지 않게 한다(거짓 진술로 쓰는 오답 보기는 허용). 검수는 배분표를 검색해 확인 | `exam-designer`, `study-quiz`, `review-overall` |
| R3 | **과목별 형식 권장표**: 수학(계산·풀이 과정 서술), 과학(실험·그래프), 사회(그래프·지도·표), 역사(연표·사료·인물 짝), 국어(지문·문법·표현), 영어(어법·대화·독해·영작) | `exam-designer`, `study-quiz` |
| R4 | **선택지 길이 균형**: 정답을 가장 긴 보기로 만들지 않는다. 오답도 같은 구조·길이로 쓴다. 빌드가 단원별 '정답이 가장 긴 보기' 비율 40% 초과 시 경고, 검수가 확인 | `study-quiz`, `review-format`, `build_library.py` |
| R5 | **출제 범위·지엽성**: notes의 '꼭 외울 것'·'시험 포인트'에 있는 내용을 우선하고, 연도·고유명 단답은 단원당 최대 1문항, 교과서가 강조하지 않는 세부 수치는 출제하지 않는다 | `exam-designer`, `study-quiz`, `review-overall` |
| R6 | **원문 이설·해석 용어 절차**: 연도·수치가 문서마다 다르거나 원문에 없는 해석 용어(예: 반어법)는 정답 근거로 쓰지 않고 notes의 '문항에서 다루지 않은 것'에 기록, 검수는 이를 확인 | `study-quiz`, `review-content` |
| R7 | **서술형 감점 요소**: 영작은 철자·시제·어순 오류 감점, 계산 서술형은 풀이 단계별 배점, 조건어 누락 시 해당 기준 0점을 기준 문장에 명시 | `study-quiz`, `review-format` |
| R8 | **축약 모드 표기**: 축약 검수는 사용자가 지시한 작업에서만 쓰고, `status.json`에 `mode: reduced`와 사유를 기록하며 책을 '샘플'로 둔다. 정식 검수 때 해제 | `study` 스킬, `build_library.py`(book.json에 reviewMode) |
| R9 | **교과서 용어 우선**: 교과서·자습서가 있으면 그 용어·수준을 따르고, 공개 자료만 쓴 경우 notes 첫머리에 '교과서 용어와 다를 수 있음'을 적는다 | `study`, `review-content` |

## 5. 남은 과제 (이번에 하지 않은 것)
- 샘플 6권을 개정 규칙(배점·서술형 개수·선택지 길이)에 맞게 **다시 만들기**: 사용량이 필요해 이번에는 하지 않았다. 지금 샘플은 위 진단 때문에 정식 시험지로 쓰기에는 배점이 거칠다.
- 실제 학교 기출·교과서가 들어오면 이 문서의 판정을 다시 검증한다.
- 교사 검수, 학생 응시 결과(정답률·변별도)를 받아 난이도 표시를 보정한다.
- `study-explain`(오답풀이)과 `frontend-slides`는 이번 진단에서 문제가 드러나지 않아 수정하지 않았다.
