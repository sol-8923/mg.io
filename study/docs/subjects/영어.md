# 영어 출제 기준

> 마지막 갱신 2026-11-15 (시작 전 초안 — 영어 교과서 단원을 처음 만들 때 이 문서를 먼저 읽고, 단원 통과 후마다 5·6·7번을 채운다).

## 1. 출제 형식
| 선택형(5점) | 서술형·단답형 |
|---|---|
| 어휘(문맥 속 낱말 뜻), 어법 판단(밑줄 중 어색한 것), 대화 완성(빈칸), 독해(내용 일치·지칭·제목·순서 배열·빈칸 추론) | 조건 영작(주어진 단어·조건), 오류 고쳐 쓰기, 괄호 안 단어를 알맞은 형태로, 대화 완성 쓰기 |
- 듣기 평가는 낼 수 없으므로 대화문·지문으로 대신한다.

## 2. 지문·자료 규칙
- **지문이 있어야 풀리는 독해·대화 문항은 지문(영어 본문)을 문항에 모두 넣는다.** 교과서 본문 문장을 길게 그대로 쓰지 않고, 같은 어휘·문법·주제로 **새로 쓴 지문**(교과서 문장은 짧은 인용만)을 쓴다.
- 어휘·어법 문항은 문항 안의 문장만으로 풀려야 한다. 교과서 핵심 어휘·표현·문법(교과서 '핵심 표현')에서 출제한다.
- 한국어 해석은 정답이 아닌 보조로만(발문은 한국어, 선택지는 영어). 수준은 중학교 교육과정 어휘 범위.

## 3. 오답·서술형 설계
- 어법 오답은 학생이 실제로 하는 실수(주어-동사 수일치, 시제, 관계대명사, to부정사/동명사, 비교급)로 만든다.
- 독해 오답은 지문에 일부만 맞는 진술, 지문 반대, 지문에 없는 내용으로 만든다.
- 서술형 채점은 **어휘 사용·어법·철자**로 항목을 나누고 부분 점수를 준다. 조건(단어 수·주어진 단어 모두 사용·시제)을 `answerHint`에 명시한다.
- 서술형 정답이 여러 가지면 모범 답안 외에 허용 답안을 rubric에 적는다.

## 4. 단원 유형별 지침
- 대화 중심 단원: 상황 제시 → 알맞은 표현 고르기/쓰기. 읽기 중심: 지문 + 내용 파악. 문법 중심: 문장 판단·고쳐 쓰기.

## 5. 자주 나온 반려 사유 (출제 전 체크리스트)
- [ ] 지문을 직접 문항에 넣었는가. 지문 속 정답을 다른 문항이 알려 주지 않는가.
- [ ] 노트·해설의 사실·번역을 원문과 대조했는가. 정답이 둘로 읽히지 않는가.
- [ ] 서술형 허용 답안과 조건이 명확한가.
