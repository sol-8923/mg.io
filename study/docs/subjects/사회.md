# 사회 출제 기준

> 적용 책: g1s2-social(비상교육 사회 ①, 지리 6 + 일반사회 6단원). 마지막 갱신 2026-11-15 (시작 전 초안, 첫 단원 통과 후부터 이력 기록).

## 1. 출제 형식
| 선택형(5점) | 서술형·단답형 |
|---|---|
| 그래프·지도·표 해석(기후 그래프, 인구 피라미드, 지역 비교표 등), 〈보기〉 합답, 개념 비교, 사례 적용(법·인권·민주주의 사례 → 개념), 지역 특성 짝짓기 | 조건어 서술(원인·영향·해결 방안), 용어 단답, 자료를 해석해 쓰기 |
- 지리 단원은 **자료(지도·그래프·표) 해석형 비중을 높인다**(선택형 12개 중 4개 이상). 일반사회 단원은 **사례 적용형**을 높인다.

## 2. 지문·자료 규칙
- 지도·그래프·표·사진 자료는 **문항에 직접 넣는다**(SVG로 새로 그림, 교과서 그림을 베끼지 않음). 문항을 풀 때 필요한 값(범례·축·단위·연도)은 자료 안에 모두 있어야 한다.
- 직접 만든 모식 자료(기후 그래프 등)는 캡션에 '모식도'라고 쓰고 실제 관측 자료처럼 쓰지 않는다. 통계는 **연도와 출처 표기**를 하고 교과서 값과 맞춘다.
- 사례·기사·대화문은 발췌해서 문항에 제시한다(교과서 문장은 짧게 인용, 나머지는 새로 만든 사례). 문항이 교과서 본문을 읽었다고 가정하지 않는다.
- 교과서·교사용 교과서·지도서에서 연도·수치가 다르게 나오면 사용자에게 올린다(R6).

## 3. 오답·서술형 설계
- 오답은 **지역·개념을 서로 바꾼 진술**(다른 대륙의 특징, 비슷한 개념의 정의 교환), 원인과 결과의 뒤바뀜, 과한 일반화로 만든다.
- **가치 판단 의견 문항 금지**(`../도덕-출제-기준.md`와 같은 원칙): 교과서가 정한 개념·기준을 묻는다. 논쟁적 사안은 사실·개념 중심으로.
- 서술형은 '원인–과정–결과/영향' 또는 '개념 정의 + 사례' 구조로 채점 기준을 나누고 조건 낱말 항목을 따로 둔다.
- 같은 사실(예: 기후 유형의 정의 수치)을 여러 슬롯 정답에 반복하지 않는다. 샘플 사회에서 미해결로 남은 R2 문제가 이것이다.

## 4. 단원 유형별 지침
- **지리(세계화·대륙별 지역)**: ① 자연환경(기후·지형) ② 인문환경(종교·인구·산업·도시) ③ 지역 간 상호작용·변화를 슬롯으로 고르게 배정. 지역별 특성은 비교표로 정리한 뒤 짝짓기·합답으로 출제. 지도 문항은 위치 번호(가~마)를 SVG에 직접 그린다.
- **일반사회(사회화·문화·정치·법·인권)**: 개념 정의 → 사례 판단 → 〈보기〉 합답 순으로 난이도를 올린다. 법·재판·기본권은 **구체적인 사건 사례 문장**을 주고 해당 개념을 고르게 한다(실존 개인 사건·실명 금지).
- 교과서의 '연결! 미래로(직업 소개)'·'범교과 프로젝트' 활동은 출제 범위에서 제외한다.

## 5. 자주 나온 반려 사유 (출제 전 체크리스트)
(첫 단원 통과 후 채운다. 국어에서 확인된 아래 항목은 사회에도 적용)
- [ ] 노트·해설의 사실·수치를 원문과 대조했는가(기억으로 쓰지 않았는가).
- [ ] 인용·수치의 쪽수가 맞는가.
- [ ] 다른 문항의 정답·조건 낱말을 그대로 알려 주지 않는가.
- [ ] 합답형 정답만 3개짜리 조합이 아닌가, 정답이 가장 긴 보기가 아닌가.

## 6. 다음 단원에서 개선할 것
- 지도·그래프 SVG의 **수치와 해설·보기 일치**를 출제 직후 스크립트로 확인(그래프 값 ↔ 보기 문장).
- 지리 단원의 서술형은 '자료에서 근거를 찾아 쓰기' 구조(자료 제시 필수).
- 지엽적 수치(연도·인구 정확 값) 단답은 단원당 최대 1문항.
