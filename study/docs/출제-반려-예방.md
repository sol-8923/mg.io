# 출제 반려 예방 지침 (모든 과목 공통)

> 문제를 만들 때마다 4중 검수에서 **반복해서 반려된 사유**를 모아, 만드는 단계에서 미리 막는 규칙이다. 국어·사회 8개 단원의 검수 기록(약 40회 반려)에서 뽑았다. 과목별 기준(`subjects/<과목>.md`)과 함께 읽고, 새 반려 사유가 나오면 여기와 그 과목 5번에 **같이** 추가한다.
> 자동으로 잡을 수 있는 것은 `engine/precheck_unit.py`(규칙 파일 `engine/_precheck_extra.py`)가 검사한다. **검수에 보내기 전에 반드시 `✖ 0건`을 만든다.**

## 1. 만들기 전에 정해 둘 것 (설계 단계)
1. **사실 배분표**: 설계도 `analysis`에 "어느 사실을 어느 슬롯의 정답으로 쓰는지"를 적는다. 같은 사실을 두 슬롯의 정답이나 참인 보기로 반복하지 않는다(반려 1위).
2. **자료 세트를 먼저 나눈다**: 지문·그림·표 하나를 여러 문항이 쓸 때 그 문항들끼리 정답을 알려 주지 않도록, 문항마다 필요한 부분만 넣는다.
3. 교과서·교사용·지도서의 표현이 다른 곳은 **출제하지 않고** notes 끝에 '불일치'로 기록한다(둘 다 맞는 사례로만 낼 수는 있다).
4. 정답 번호 배분표(a·b 변형 각각 ①~⑤ 3~4개, 3연속 금지)를 설계도에 적는다.

## 2. 문항을 쓸 때 (출제 단계) — 자동 점검(✖)이 있는 것
| 반려 패턴 | 막는 법 | 자동 점검 |
|---|---|---|
| 다른 슬롯의 정답·조건 낱말이 **발문·지문·보기·해설 옆 자료(refs)·그림 캡션·그림 속 글자**에 나옴 | refs·캡션에는 그 슬롯 자기 내용만. 정의 카드·사례 표에 다른 문항의 정답 문장을 넣지 않는다. 변형 a·b의 사례행도 서로 넣지 않는다 | ✖ |
| 합답에서 **정답만 3개짜리 조합**(또는 정답만 2개짜리) | 같은 크기의 오답 조합을 1~2개 더 만든다 | ✖ |
| 합답에서 **같은 기호가 5개 보기 모두에 들어감**(그 진술이 참인 것이 드러남) | 기호 위치를 섞고 거짓 진술 위치도 바꾼다 | ✖ |
| **정답이 단독 최장 보기** | 오답을 정답과 비슷한 길이·구조로. 정답을 줄이는 쪽을 먼저 | ✖(차이 3자 이상) / ⚠ |
| 정답 번호가 a·b 변형별로 쏠림(최대-최소 ≥3) 또는 3연속 | 변형별로 재배치(fixedOrder 문항은 보기 순서를 바꿔서) | ✖ |
| 발문이 '밑줄 친'을 가리키는데 지문에 표시가 없음 | 단어를 직접 지목하거나 ㉠㉡을 붙인다 | ✖ |
| 그림 속 글자가 **그림 밖으로 잘림·서로 겹침** | 여백을 넉넉히, 오른쪽 끝 라벨은 `text-anchor=end`. 이동·회전(transform)이 있는 그림은 자동 점검이 못 하니 Edge 스크린샷(창 폭 500+, 2배 확대)으로 직접 확인 | ✖(transform 없는 그림) |
| 인용문이 원문에 없음·**출처 쪽수가 인용이 실린 쪽과 다름** | 인용은 원문 그대로, 생략은 `(…)`, 쪽수는 그 문장이 실린 쪽 | ✖/⚠ |
| 단답 정답이 다른 슬롯 발문·지문에 나옴 | 정답 낱말이 다른 문항에 새지 않게 | ✖ |
| 단답 인정 답에 **지문에서 옮겨 쓴 활용형**(예: 혼란스러웠어)이 없음 | 지문에 나온 형태를 모두 인정 답에 넣는다 | 직접 확인 |
| 서술형 모범 답안이 발문 조건(문장 수)보다 김 | 모범 답안을 조건대로 | ⚠ |
| 해설 템플릿이 만든 **조사 오류**('산맥로', '원주민로', '㉡로' — 받침 뒤에 '로') | 짝짓기·합답 해설 템플릿에서 받침을 보고 '으로/로'를 고른다(㉣만 '로', 나머지 ㉠㉡㉢㉤…은 '으로') | ✖(원문자)/⚠ |
| 두 경로·두 막대 길이를 비교하는 모식도에서 **그려진 길이가 보기 진술(더 짧다/길다)과 눈으로 안 맞음** | 수치가 없는 비교 그림은 그려진 길이가 정답과 일치해야 한다(또는 가상 km 값을 표기) | 직접 확인 |
| 정답 글자((가)~(바))가 보기 순서에 따라 섞이는 문항인데 **해설·detail에 정답 글자를 고정 문구로 씀** | 해설을 만들 때 정답 글자를 변수로 받는다(보기 순서가 섞이면 고정 문구가 틀림) | ✖ |
| 모든 문항의 `source`가 같은 값(기본값 복사) | 슬롯별 근거 쪽수(설계도 사실 배분표의 쪽)로 | ✖ |
| 학생이 보는 풀이(detail·explanation·refs)에 **'지도서'·'교사용 교과서'를 근거로 적음** | 근거는 학생 교과서 쪽수로만. 교사용·지도서에만 있는 내용은 출제·정답 근거로 쓰지 않는다 | ✖ |
| 풀이가 **'앞의 문항'·다른 변형을 가리킴**(시험지에는 슬롯당 변형이 하나만 들어감) | 풀이는 그 문항만으로 읽히게 쓴다 | ✖ |
| 오답 보기 해설이 **다른 슬롯 정답 사실을 풀어 씀** — 용어 정의뿐 아니라 시대·방식 구분 문장(현대=보통 선거, 아테네=직접 참여)과 개념 정의(민주주의=생활 방식)도 포함 | 오답 해설은 '이 글·자료와 어떻게 다른지'만 쓰고, 그 개념의 참인 진술은 쓰지 않는다 | 직접 확인 |
| 서술형 채점에서 **조건 낱말 항목과 내용 항목을 한 항목에 합침**(조건 낱말을 빼면 내용을 맞혀도 0점) | 조건 낱말 항목(1점)과 내용 항목을 분리하고 조건 낱말의 활용형을 허용 표현에 적는다 | 직접 확인 |
| 연결형에서 **한 사례 카드에 두 개념의 교과서 핵심 문장**이 함께 들어가 복수 정답 | 카드마다 한 개념의 특징만, 교과서 정의 문장을 그대로 쓰지 않는다 | 직접 확인 |
| 섞이는 보기(fixedOrder 아님)가 **다른 보기를 가리킴**('이런 활동', '앞의') | 각 보기는 그 보기만으로 읽히게 쓴다(합답·순서 고정 문항은 fixedOrder 사용) | ✖ |
| 해설 템플릿의 **'은(는)·을(를)' 병기** | 받침을 판정해 정확한 조사를 쓴다 | ⚠ |
| 해설의 '해마다'가 그림의 값 간격과 안 맞음 | '조사한 해마다', '3년 간격' 등 자료대로 | ⚠ |

## 3. 자동 점검이 못 잡아서 직접 확인할 것 (검수자가 자주 짚는 것)
- **복수 정답**: 오답 보기가 사실은 참일 수 있는지, 발문이 '배경'인데 보기에 경과·결과가 섞이지 않았는지.
- **지문 규칙**: 특정 사례·글·자료를 묻는 문항은 그 자료를 문항에 넣었는지. 해설·detail·refs가 지문에 없는 표현·장면을 쓰지 않는지.
- **부정형 문항**의 '참인 보기 4개'가 지문·자료 안에 근거가 있는지.
- **쉬운 문항 방지**: 사례 지문에 정답 개념어가 그대로 들어가 읽기만 해도 답이 나오지 않는지, 오답이 다른 보기와 정면으로 모순되어 소거만으로 풀리지 않는지.
- 사례가 단원 안 다른 슬롯과 겹치지 않는지(같은 도시·같은 사례 반복).
- 교과서 용어 표기(띄어쓰기·'~의 구조' 등)가 교과서와 같은지. 지도서에만 있는 용어는 쓰지 않는다.
- 통계를 인용하면 캡션에 출처·연도. 직접 만든 모식 자료는 캡션에 '모식도'.
- 서술형 채점 기준의 점수 합 = 배점, 허용 표현 구체적, 조건 낱말은 다른 슬롯에 나오지 않음.

## 4. 작업 순서 (제작자)
1. notes → 설계도(사실 배분표·번호 배분표 포함) → `gen.py`로 문항 생성(단원 폴더 안에서만, 다른 단원 스크립트 실행 금지).
2. `python engine/build_library.py --check-unit drafts/<책>/<단원>` → 오류 0·경고 0.
3. `PYTHONIOENCODING=utf-8 python engine/precheck_unit.py <책> <단원> --pages a-b --src 교과서.txt "교사용 교과서.txt"` → **✖ 0건**, ⚠는 새로 쓴 사례·인용만 남게.
4. 그림이 있으면 Edge 스크린샷으로 2배 확대 확인(특히 transform이 있는 그림).
5. 이 문서의 3번을 한 번 훑고 검수로 보낸다.

## 5. 갱신 규칙
- 검수에서 새로운 종류의 반려가 나오면: ① 자동으로 잡을 수 있으면 `engine/_precheck_extra.py`에 규칙을 추가하고 ② 이 문서 2·3번에 한 줄 추가하고 ③ 그 과목 `subjects/<과목>.md` 5번에 사례를 적는다.
- 자동 점검이 **통과한 단원을 검수자가 반려**하면 점검 규칙이 빠진 것이니 규칙을 보강한다.

## 6. 기출 원문 편입 문항 추가 규칙 (2026-11-15, 사회 2024 기말에서)
- 기출 문항의 **해설·refs는 그 문항의 정답 근거(그 문항의 정의·판단 기준) 한두 줄 text 카드**로 쓴다. 같은 단원 새 문항의 정답을 정리해 주는 표·목록은 넣지 않는다. 단, "교과서 p.NN에서 확인해 보세요" 같은 안내문만 두면 반려된다(그 문항 정답 근거 정의는 직접 쓴다).
- 오답 해설은 "근거가 없어요/교과서에 없어요"로만 배제하지 않고, 정답과 공통인 특성(예: 감시·비판)을 배제 근거로 쓰지 않는다. 정답 해설은 보기 문장을 되풀이하지 않고 이유를 쓴다.
- 교과서 학생용에 없는 사실을 해설에 쓰면 '(교과서 밖 일반 상식)'을 붙이고, 교사용·지도서는 근거로 쓰지 않는다.
- 그림에 범례를 넣으면 실제 선 모양과 일치(예: 점선=아니오). 합답(㉠~㉣ 조합) 기출도 `fixedOrder:true`.
- 기출 편입에서 **제외**하는 경우: ① 현재 교과서에 해당 내용이 없음(예: 대통령제·의원내각제, 공법·사법 구분, 선거 공영제·게리맨더링) ② 정답이 하나로 정해지지 않거나 원문 오류 가능성(예: 구청장도 선출 대상인 17번) ③ 새 문항과 같은 사실이라 해설을 쓰면 새 문항 정답이 노출되는 경우. 제외 사유는 단원 review/changelog.md에 적는다.
- **기출 문항은 2라운드 통과 실패 시 폐기**: 해설·refs를 두 번 고쳐도 검수를 못 넘으면 그 기출은 넣지 않는다(시간·비용 절감). 반려 사유가 반복될 법한 문항(교과서 밖 용어, 정답 모호)은 처음부터 제외한다.

## 7. 과학 4개 단원(상태 변화·힘·기체·태양계) 1라운드 반려에서 추가 (2026-11-16)
- **기출 슬롯을 포함해 사실 배분표를 짠다**: 기출 원문은 시험지에 늘 들어가므로 새 슬롯이 기출 보기·발문과 같은 사실·사례를 정답이나 참인 보기로 쓰면 정답이 확정된다. 기출 정답 사실을 설계도 `facts`에 먼저 적고 새 슬롯은 다른 사실을 고른다.
- **서술형·단답이 선택형의 정답 사슬·소재를 되풀이하면 반려**(합답 보기·refs 표·오답 해설 포함). 서술형 소재는 교과서 문장·확인문제를 그대로 쓰지 않는다.
- **그림 객체 수(입자 수 등)·화살표 방향·수치는 코드로 assert**하고 캡션·발문·해설과 일치시킨다. 캡션에 정답 정보를 쓰지 않는다.
- **교과서 밖 사실·수치는 해설의 모든 필드에 '(교과서 밖 일반 상식)'**, 근거 쪽수는 실제 그 쪽에 있는 내용만. '원문 설명' 같은 메타 문장 금지(기출 해설 반려 반복).
- **일반 명제로 읽히는 정답 보기·기간 발문은 범위를 한정**해 사실 오류·복수 정답을 막는다.
- **참고 자료 카드·비교표는 문항별 자기 근거만**. 공유 카드에 다른 슬롯 정답 정리 금지.
- `precheck_unit.py`는 복수 정답(배열 answer) 선택형에서 TypeError — (2026-11-16 수학 작업에서 보강 완료: `_precheck_extra.py`의 `A1()`, `precheck_unit.py`의 복수 정답 해설 개수).


## 8. 수학 4개 단원(좌표평면·기본 도형·평면도형·입체도형) 반려에서 추가 (2026-11-16)
- **수치·값 전수 대조**: 새 문항의 정답뿐 아니라 **선택지 값·해설 중간값**이 같은 단원 다른 슬롯(기출 슬롯 포함)의 정답 값과 같지 않은지 코드로 대조한다(같은 반지름·같은 n각형·같은 3-4-5 도형을 슬롯마다 따로 정한다). 값이 같으면 시험지에서 한 문항의 선택지가 다른 문항의 정답을 알려 준다.
- **오답 해설의 진단 식은 assert**: '~로 계산한 값', '~만 센 값'은 그 식을 실제로 계산해 보기 값과 일치함을 코드로 확인한다. 안 맞는 값은 비교('더 짧아요')로 쓴다. 수정 라운드에서는 지적한 문장이 소스(gen.py)에 반영됐는지 diff로 확인한다.
- **〈보기〉·refs의 공식 단언**: 합답의 참인 진술과 refs 표가 다른 슬롯의 핵심 공식을 정리해 주면 안 된다. 한 진술이 대부분의 보기에 들어가 그 진술의 진위만으로 정답이 정해지는 구성도 금지(같은 기호 4/5).
- **그림**: 라벨은 그 선분·각 옆(좁은 도형의 높이는 축 옆·지시선), 그래프 선의 끝점·강조점이 소문항이 묻는 좌표와 겹치지 않게, 캡션에 정답(관계식·값) 금지, 색칠 넓이는 그림의 도형에서 다시 계산해 정답과 일치 확인, 반드시 Edge 렌더링 확인.
- **교과서 밖 용어·선수 지식**: 닮음·같은 쪽 안쪽 각·바깥쪽 엇각·보각 등으로 정답 근거를 대지 않는다. 필요한 길이는 문항·그림에 준다. 각 표기는 교과서 기호(∠AOB, ∠a)만.
- **서술형 이유 쓰기**: 채점 기준이 특정 성질만 인정하면 다른 타당한 근거(평각·맞꼭지각 등)도 인정하도록 쓰거나 발문에서 근거를 지정한다. 다른 과목용 '조건 낱말' 안내 템플릿을 수학에 복사하지 않는다.
- **정답 번호 분배는 기출 포함 전체를 a·b 변형별로 집계**(새 슬롯만 센 값과 섞지 않는다).
- **문자열 저장 점검**: 해설에 글자 그대로의 역슬래시+n이 저장되지 않았는지(questions.json 전체 문자열에 역슬래시 없음) 기계 점검에 넣는다.
- 점검 규칙 추가(2026-11-16, `_precheck_extra.py` R-M): 해설 등 문자열에 글자 그대로의 역슬래시+n(✖), 선택지 값이 같은 단원 다른 슬롯의 정답 값과 같음(⚠).
- **오답 진단의 숫자 출처**: 값을 교체할 때 해설을 임의 숫자 식으로 메우면 다른 슬롯 정답 노출·거짓 진단이 된다. 진단 식의 숫자는 그 문항에서만 나오게 하고, 안 되면 비교형으로 쓴다. detail '확인' 줄도 발문·그림에 주어진 값만.
- **서술형 소문항 값 대조**: 서술형 (1)~(n) 최종 값이 같은 단원 다른 슬롯(기출 객관식 선택지·기출 서술형 정답 포함)의 같은 단위 값과 겹치지 않는지 코드로 대조한 뒤 검수에 보낸다(수학 u7 S01에서 반려).
- **8. (과학 3~4라운드) 소재만 바꾸고 사실이 같으면 다시 반려된다**: 새 슬롯은 기출 보기·발문에 없는 사실로 고르고, 없으면 슬롯 삭제. 오답 해설에 근거 없는 계산 진단 금지. 그림을 바꾸면 해설의 기호·방향 서술도 재검증(그림 좌표와 대조). 교과서 스스로 하기·단원 점검·사고력 문제의 소재·수치 복제 금지. 해설 수정·삭제 후 blueprint의 intent·facts에 삭제 슬롯 언급이 남지 않았는지 확인.


## 9. 기출 편입 추가 규칙 (국어·사회 2025 편입 검수에서, 2026-11-16)
- 기출 오답 해설은 보기에 이름만 나온 **다른 개념의 뜻을 정의 문장으로 풀지 않는다**(같은 단원 Q 슬롯 정답 근거가 됨). 단, 그렇다고 모든 오답을 같은 문장("이 설명과 달라요")으로 반복하거나 정의 없이 부정만 하면 해설 검수에서 반려된다 → 해설이 부실해질 문항은 **처음부터 제외**한다.
- 발췌한 지문으로 만든 문항의 해설은 교과서 원문에만 있는 장면을 '글에서'라고 쓰지 않는다. 문항에 제시된 지문 안 근거만 쓴다.
- 발문의 기호(㉠~㉤, ⓐ~ⓔ)와 해설이 말하는 기호가 지문 표기와 일치해야 한다. 밑줄 범위는 `[ ]`로 표시하되 같은 문항의 모든 기호에 일관되게 적용하고 발문 안내문과 일치시킨다.
- 보기가 ㉠~㉤ 같은 기호로 시작해 순서대로 나열된 선택형에는 합답이 아니어도 `fixedOrder:true`. detail은 3문장 이상.
- source 쪽은 개념이 실제 설명된 쪽(단원 도입·표지 쪽 금지). 문항이 묻는 사고 유형이 그 단원 교과서 학습 목표에 없으면 배치하지 않는다.
- 오답 해설에서 "하나를 잘못 구한 값" 같은 경로를 단언하려면 실제로 그렇게 나오는지 역산한다(수학·과학).
- 조건이 원본 그림에 표시돼 있으면 발문에 말로 다시 쓰지 않는다.

## 10. 도덕 ① 10개 단원 검수에서 추가 (2026-11-17)
> 정책 확인: 해설·refs의 다른 문항 정답 개념 풀이는 결함이 아니다(`subjects/README.md` 정답 노출 정책). 아래는 **문항 본문**, **서술형 쪽지·모범 답안**, **사실 오류**, **형식**에 관한 것이다.

**출제 설계**
- **서술형(논술) 소재는 처음부터 따로 설계한다.** 서술형 쪽지·사례는 같은 단원 선택형의 지문·보기 장면과 겹치지 않아야 하고, 모범 답안·채점 요소가 선택형의 정답 문장·참인 보기와 같은 표현이면 새로 쓴다(10개 단원 중 8개가 이 사유로 반려됨). 서술형이 요구하는 개념어도 선택형 발문·보기에 단언하지 않는다.
- **새 슬롯을 만들거나 바꾸면** 새 정답 사실이 기존 슬롯의 발문·보기·지문에 이미 있는지, 새 문항의 보기·지문이 기존 슬롯 정답을 알려 주는지 **양방향**으로 대조한다(예: 기출 슬롯 때문에 같은 사실이 한 단원에 둘 생기는 경우).
- **한 슬롯의 오답이 다른 슬롯의 참인 진술과 정면으로 모순**되면 그 오답이 소거로 확정된다. 같은 단원 슬롯들의 참/거짓 진술을 한 표로 놓고 겹침을 확인한다.
- **정답 용어가 같은 기출이 한 단원에 둘 이상**이면 하나만 편입한다. **근거가 지도서·교사용에만 있는 기출**, 현재 학생용 교과서에 근거가 없는 기출은 편입하지 않는다(2라운드 안에 통과 못 하면 폐기하는 기존 규칙과 같음).
- 서술형 `answerHint`가 'N문장 이상'을 안내하면 모범 답안의 각 선택지 답이 N문장 이상이어야 한다. 채점 항목은 발문 조건과 맞아야 한다(발문에 없는 숨은 항목 금지). 조건 낱말 항목은 따로 분리한다.

**사실·표기**
- 〈보기〉·쪽지에 없는 시간·장소·행동·말을 해설·detail이 단언하지 않는다(인용은 원문 그대로). 지문과 맞아 보이는 오답 용어는 해설로 덮지 말고 **보기를 바꾼다**.
- 교과서의 개념 정의를 해설에서 넓혀 사례 분류의 근거로 쓰지 않는다('상대방' 탓 → '상대방이나 다른 것' 같은 확대 금지).
- 변형 a·b 풀이가 서로를 가리키지 않는다('이번에는 …가 바뀌었어요' 금지). 한 변형의 해설을 복사해 쓰면 다른 변형 〈보기〉에 없는 내용을 단언하게 된다.
- 순서나 단계가 없는 나열(방법 3가지 등)을 '→'로 이어 단계처럼 쓰지 않는다(슬라이드·개념도 포함). 교과서에 인과가 없는 화살표도 같다.
- 이름·사례를 바꾼 뒤에는 받침에 맞게 조사(은/는·이/가)를 다시 점검한다.
- 인용하거나 그림을 설명할 때 낱말 하나(예: '살아 있는')가 빠지면 뜻이 바뀐다. 원문과 글자 단위로 대조한다.
